# 엘라이 섬 · 발표자용 10분 시연

프로젝터를 가로 화면(1366×768 권장)에 맞추고 [시연 주소](https://elai-indol.vercel.app/?demo)를 열어요. **처음 상태로 시작**을 누르면 마을에서 출발해요. 오른쪽 **메뉴 → 소리 크기 → 작게**에서 스피커를 확인하고 닫아요. 이어서 연습할 때는 **시연 시작**을 눌러요.

**시연 → 미션 바로 열기** 아래에서 장 번호를 고르면 그 장의 미션 이름이 보여요. **장으로 가기**는 장의 시작 상태로 기록을 다시 만들어요. 화면만 바꾸려면 미션 목록에서 바로 열어요.

| 시간 | 누를 곳과 동작 | 학생에게 들려줄 말 |
|---|---|---|
| 0:00–1:00 | 마을 빈 바닥을 눌러 걷고 **길 안내**를 눌러요. 발자국을 따라가며 목표 NPC를 가리켜요. | “발자국은 누구에게 가야 하는지 알려 줘요.” |
| 1:00–2:00 | **시연 → 미션 바로 열기 → 1장 → 곧은 길**. ‘오른쪽으로’ 블록을 네 번 넣고 **▶ 실행**을 눌러요. 결과 창에서 **확인**을 눌러요. | “한 블록이 한 걸음이에요. 로비는 정한 차례대로 움직여요.” |
| 2:00–3:15 | **시연 → 장으로 가기 → 5장**으로 부품을 갖춰요. 다시 **시연 → 미션 바로 열기 → 0장 → 연습 전투**. 공격 블록을 넣고 한 번 실행해요. 한 라운드만 보여 줄 때는 새로고침 → **시연 시작**으로 돌아와요. | “상대가 무엇을 할지 살피고 행동을 정해요. 강타가 올 때는 막을 수 있어요.” |
| 3:15–4:45 | **시연 → 미션 바로 열기 → 5장 → 로비 학습 칩**. 뛰는 높이와 점무늬 수가 작은 네 예시는 ‘친구’, 큰 네 예시는 ‘장난꾸러기’로 골라요. **친구 예시만**, **두 종류 모두**를 차례로 골라 각각 **학습하기 → 새 예시로 시험**을 눌러요. 50%와 100% 막대를 비교하고, 장난꾸러기 예시가 빠졌다는 답을 골라 저장해요. | “이름표를 붙인 예시로 배워요. 배울 때 보지 않은 예시로 시험해요.” |
| 4:45–6:00 | **시연 → 미션 바로 열기 → 7장 → 동생에게 양치 알려 주기**. ‘누구처럼’에 ‘친절한 치과 선생님처럼’을 넣고 **젠에게 부탁하기**. 결과를 본 뒤 ‘무엇을’에 양치의 까닭을 골라 **고쳐서 다시 부탁하기**를 눌러요. | “같은 부탁이라도 누구에게 무엇을 설명할지 알려 주면 답이 달라져요.” |
| 6:00–7:00 | **시연 → 미션 바로 열기 → 8장 → 성의 초상화**. 실제 로봇은 네 대씩인데 기록이 8·2·0인 표를 가리켜요. 바퀴·발·날개를 4·4·4로 맞추고 **고친 자료 확인**을 눌러요. | “날개 로봇이 기록에 빠졌어요. 실제 모습을 살펴 자료를 고쳐요.” |
| 7:00–9:00 | **시연 → 마을 과일 가게 → 들어가기**로 상자와 로봇을 보여 줘요. **시연 → 마을 과일 가게 → 놀이 열기 → 1판 첫 학습**. 빨간 사과와 바나나 카드를 하나씩 넣고 **학습하고 시험 보기**를 눌러요. | “로봇은 색·모양·무늬가 닮은 예시의 이름표를 따라 해요.” |
| 9:00–10:00 | 창을 닫고 **시연 → 엔딩 앞**. 로비의 대화를 눌러 넘기고 여덟 배지와 칭호를 보여 줘요. **마을에서 계속 탐험하기**로 마쳐요. | “AI가 도와줘도 마지막에는 사람이 살피고 결정해요.” |

**5분 시연**은 마을 조작 30초 → 곧은 길 1분 → 과일 가게 첫 학습 2분 → 엔딩 1분 30초로 진행해요.

**중간 복구** 미션·놀이 창은 ×로 닫고 **시연**에서 다음 장이나 미션을 골라요. 전투 중 시간이 길어지면 새로고침 → **시연 시작**으로 월드에 돌아와요. 전체를 다시 보려면 **시연 → 처음 상태로**를 눌러요.

**교사 페이지**는 발표자가 미리 실제 학급 계정으로 로그인하고 보여 줄 학급 화면을 준비해요. 학급 화면 아래쪽 **마을 놀이 기록** 표에서 학생별 놀이 별을 볼 수 있어요. 시연 모드의 기록은 이 기기의 시연 저장에만 남아서 교사 페이지에는 나오지 않아요.
