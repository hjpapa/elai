# Codex 작업 C13 — 마을 공방(들어가는 건물)과 코딩 인형뽑기 그림

## 목표
2.5D 개선 4단계예요. 학생들이 바란 "들어가는 건물과 미니게임"의 첫 건물이 **마을 공방**이고, 첫 놀이는 **코딩 인형뽑기**예요.
엔진은 Claude가 먼저 만들었어요. 지금은 임시 그림(단색 도형)으로 끝까지 돌아가요.
- 마을 오른쪽의 공방 건물 칸으로 걸어 들어가면 공방 안(실내 맵 `workroom`)으로 가요. 앞 가장자리 문 매트를 밟으면 마을로 나와요.
- 공방 안 인형뽑기 기계에서 학생이 블록(화살표 → 앞으로·돌기 → 반복, 그리고 새 블록 '집기')으로 집게를 움직여 주문한 인형을 뽑아요. 운이나 코인은 없어요.
- 판을 처음 성공하면 섬 친구 인형이 공방 왼쪽 벽 앞 방석에 앉아요.

이번 작업은 **새 그림 21개(모두 2배)**와 C12 검토에서 남은 **동굴 바닥 다시 그리기**예요. 네 단계로 나눠 단계마다 커밋해요.

## 공통 규칙
- **팔레트**: 64색이 가득 찼어요. 지금 색만 써요(바꾸거나 늘리지 않아요). 색이 모자라면 가까운 색으로 그리고 진행 기록에 적어요.
- **원본**: 2배 원본은 `assets-src/hires/<kind>/<key>.txt`예요. 새 키라서 옛 1배 원본은 없어도 돼요.
- **규격**: 크기는 정확히 목록 × 2, 발은 아래 가운데에서 4px 위, 반투명 픽셀 없음, 발밑 그림자 없음(게임이 그려요).
- **스타일**: C11·C12처럼 빛은 왼쪽 위, 바깥 외곽선, 재질마다 3~4단 명암이에요. 공방 안은 따뜻하고 아늑하게(나무·크림색 벽·분홍 포인트), 마을과 같은 섬으로 보이게 해요.
- 실제 브랜드·기존 게임의 기계·캐릭터를 따라 그리지 않아요. **동전 넣는 곳·돈 표시는 그리지 않아요**(놀이는 프로그램으로만 해요).

### 1단계: 공방 건물과 방
- **`prop-workshop`**(마을에 서 있는 공방 겉모습): C11 `prop-house`와 같은 크기·시점·지붕 방식으로, 한눈에 다른 집과 구별되게 그려요(문 위 작은 인형 간판, 큰 진열 창 등).
  - 프레임 0은 문 닫힘, 프레임 1은 문이 열리고 창에 따뜻한 불빛이 비쳐요. 게임은 들어갈 수 있는 문이라서 늘 **프레임 1**을 보여 줘요.
  - 학생이 이 집 칸으로 걸어 들어가요. 문은 그림 아래 가운데(화면 쪽)에 있어요.
- **`tile-room`**: 공방 마루. 7장 프롬프트 공방의 `tile-wood`와 구별되는 따뜻한 널마루예요. 이웃 칸과 이음새 없이 이어지고, 같은 무늬가 줄지어 보이지 않게 해요.
- **`tile-rug`**: 인형 모음 깔개(2칸 × 5칸으로 깔려요). 칸마다 테두리를 그리지 말고, 이어 깔았을 때 하나의 천처럼 보이는 잔무늬로 그려요.
- **`tile-doormat`**: 나가는 문 매트. 마루 위에 놓이는 그림이라 매트 바깥은 투명이에요. 프레임 0은 매트만, 프레임 1(게임이 보여 주는 쪽)은 문틈 빛과 바깥(화면 아래)을 가리키는 화살표 무늬예요.
- **`block-room-wall`, `block-room-window`**(높은 벽, `docs/asset-spec.md` "건물 안 높은 벽"):
  - 2배 기준 위 32px은 윗면 마름모(벽 두께, 나무 테두리)예요. 그 아래로 두 옆면이 80px 내려와요.
  - 왼쪽 옆면은 오른쪽 뒤 벽(맵 y=0 줄)의 방 쪽 면이라 밝아요. 오른쪽 옆면은 왼쪽 뒤 벽(x=0 줄)의 방 쪽 면이라 조금 어두워요.
  - 아래쪽에 굽도리(걸레받이) 띠, 벽지는 아주 약한 무늬예요. 같은 줄에 이어 놓았을 때 옆면 무늬·굽도리·윗면 테두리가 끊기지 않아요.
  - 창문 벽은 두 옆면의 같은 높이에 창이 있어요(창이 면 가장자리를 넘지 않게). 창밖은 밝은 하늘색이에요.
- **가구**:
  - `prop-workbench`: 공구·실타래가 놓인 작업대
  - `prop-toybox`: 뚜껑이 열린 장난감 상자
  - `prop-plant`: 둥근 잎 화분
  - `prop-floorlamp`: 따뜻한 빛의 스탠드(불빛은 게임이 더해요)
  - `prop-cushion`: 인형을 앉히는 납작한 둥근 방석. 인형이 같은 발 기준점에 앉으니 방석 윗면을 낮게(2배 기준 10px 안팎) 그려요.

### 2단계: 인형뽑기 기계와 놀이 그림
- **`prop-claw-machine`**: 한눈에 인형뽑기 기계로 보여야 해요.
  - 위쪽 유리 상자 안에 인형 몇 개와 집게가 보이고, 분홍 몸체 앞에 출구가 있어요. 맨 위에 불빛 간판이 있어요.
  - 프레임 0·1은 간판 불빛이 번갈아 켜져요. 게임이 0.7초마다 바꾸고, 위쪽에 청록 빛 무리를 더해요.
  - 동전 넣는 곳은 그리지 않아요.
- **`prop-claw`**: 놀이 창의 집게(목록 16×16, 2배 32×32, 화면에서 40~60px로 커져요). 프레임 0은 벌림, 프레임 1은 오므림이에요.
  - 위 가운데에서 짧은 줄이 시작돼요. 게임이 그 위로 회색 줄을 이어 그려요.
  - 오므렸을 때 손가락 사이(아래쪽 가운데)에 인형이 매달려 보일 자리를 남겨요.
- **`icon-claw-exit`**: 위에서 본 출구 구멍이에요. 놀이 판(연보라 칸) 위에서 또렷하게 보이게, 테두리에 줄무늬를 둘러요.
- **`icon-card-grab`**: '집기' 블록 카드. 다른 `icon-card-*`와 크기·선 두께·여백을 맞추고, 집게 모양을 그려요(블록 색은 분홍이에요).

### 3단계: 섬 친구 인형
- 몹이 정화된 뒤의 웃는 모습(각 몹 그림의 프레임 3)을 **천 인형**으로 바꿔요: 둥근 몸, 바느질 선, 단추 눈, 포근한 색이에요.
- 여섯 인형은 32×32에서도, 놀이 창의 48px 그림에서도 서로 바로 구별돼야 해요.
  - 허수아비 봇: 연습장 허수아비 봇
  - 덩굴 슬라임: 잎 하나
  - 버그 벌레: 0과 1 무늬
  - 메아리 박쥐: 날개
  - 숲 수호자: 이끼 머리
  - 로비: 안테나와 얼굴 화면
- 방석 위에 앉은 모습이 자연스럽게, 발 기준점(아래에서 4px 위)에 엉덩이가 닿아요.

### 4단계: 동굴 바닥 다듬기(C12 검토에서 남은 점)
- `tile-cave`는 칸마다 같은 판돌·광물 점이라 크게 보면 격자가 눈에 띄었어요. 더 차분하게 다시 그려요.
  - 무늬 대비를 낮춰요.
  - 광물 점을 줄이고 마름모 가운데에 몰리지 않게 해요.
  - 판돌 이음새가 이웃 칸과 이어지게 해요.
- 2장 동굴·되풀이 동굴 맵에서 넓게 깔린 모습을 보고 판단해요. 수정(prop-crystal)이 더 돋보여야 해요.

## 단계마다 할 일
1. 그 단계의 2배 원본을 그려요.
2. `npm run assets && npm test && npm run build`가 통과해야 해요.
3. 검토판 `assets-preview/compare-13-<단계 번호>.png`를 만들어요(커밋되지 않아요).
   - 그 단계 키를 모두 모아 **왼쪽 임시 그림 / 오른쪽 새 그림**으로 나란히 보여 줘요.
   - 4단계는 옛 `tile-cave` / 새 `tile-cave`예요. 4×4로 이어 깐 모습도 함께 보여 줘요.
   - 1단계는 공방 방 미리보기도 넣어요. `workroom` 맵 배치대로 벽·바닥·깔개·가구를 이어 깐 그림이면 돼요.
4. 진행 기록 `docs/tasks/codex-13-progress.md`에 결과를 적어요(아래 형식).
5. 사용자가 단계마다 커밋하라고 했으면 작업 브랜치 `codex/13-workshop`에 커밋 하나를 해요.
   - 메시지는 `C13-<단계>: <이름>`이에요(예: `C13-1: 공방 건물과 방 2배 그림`).

## 게임에서 보기(포트 5176만 써요)
- `npm run dev -- --port 5176 --strictPort`로 켜요. **5173은 쓰지 않아요**(사용자의 저장 기록이 있어요).
- 그림만 볼 때: `http://localhost:5176/?gallery`
- 공방 안: 첫 화면 → "이 기기에서 체험" → 새 별명으로 시작해요. 마을 오른쪽 길의 공방 건물(로비 옆)로 걸어 들어가요.
- 인형뽑기 기계 옆에서 Space를 누르면 놀이 창이 열려요. 1·2판은 처음부터 열려 있어요.

## 진행 기록 형식(`docs/tasks/codex-13-progress.md`)
단계마다 아래를 적어요.
- 완료한 키 / 못 한 키, 아틀라스 크기(지금 2048×2048이고 27%쯤 차 있어요)
- 그림자·불빛 표(소품만). Claude가 이 표를 보고 `shadow.ts`, `light.ts` 목록을 맞춰요.
  - 지금 넣어 둔 값: 그림자는 `prop-plant` 10, `prop-floorlamp` 8이에요.
  - 불빛은 `prop-floorlamp`(아래에서 80%, 반지름 10, 금색), `prop-claw-machine`(아래에서 82%, 반지름 12, 청록)이에요.

  | 키 | 발밑 그림자 너비(논리 px, 없으면 "없음") | 불빛(높이: 아래에서 그림 높이의 %, 반지름 논리 px, 켜지는 프레임) |
  |---|---|---|
  | 예: `prop-plant` | 10 | 없음 |
  | 예: `prop-floorlamp` | 8 | 80%, 10, 모든 프레임 |

  - 작업대·장난감 상자·방석·기계처럼 바닥이 넓은 가구와 방석에 앉는 인형은 그림자 "없음"이에요.
- 더 있으면 좋을 색, Claude가 봐 줬으면 하는 그림, 고민한 점

## 완료 기준(단계마다)
- 그 단계의 키가 모두 `density: 2`이고 PNG·아틀라스 프레임이 정확히 2배예요.
- 아틀라스가 한 장 4096×4096 이내예요.
- `npm test`와 `npm run build`가 통과해요(팔레트 그대로·2배 크기·반투명 없음 포함).
- 갤러리와 공방 안에서 새 그림이 칸 가운데에 서 있어요.
  - 높은 벽은 바닥 마름모 둘레에 맞고, 이웃 벽과 이어져요.
  - 인형은 방석 위에 앉아 보여요.
