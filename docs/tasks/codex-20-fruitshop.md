# Codex 작업 C20 — 마을 과일 가게와 과일 AI 가르치기 그림

## 목표
2.5D 개선 4단계의 여섯 번째 건물이에요. 엔진은 Claude가 먼저 만들었고, 지금은 임시 그림으로 끝까지 돌아가요.
- 마을 빵집 오른쪽 (19,13) 자리가 **마을 과일 가게**예요.
  - 처음부터 열려 있어요. 걸어 들어가면 실내 맵 `fruitshop`으로 가요.
- 가게 안 학습 로봇에서 **과일 AI 가르치기** 6판을 해요(5장 지도학습·6장 데이터 양·8장 치우친 데이터).
  - 이름표가 붙은 예시 카드를 학습 상자에 넣어 로봇을 가르치고, 처음 보는 바구니 과일로 시험해요.
  - 로봇은 색·모양·무늬가 가장 많이 같은 예시의 이름표를 따라 해요. 그런 예시들의 이름표가 서로 다르면 헷갈려요.
  - 운이나 코인은 없어요.
- 판을 처음 성공하면 가게 왼쪽 벽 앞 빈 상자에 그 판의 과일이 담겨요.

이번 작업은 **새 그림 5개(모두 2배)**와 **기존 카드 그림 다듬기 1개**예요. 세 단계로 나눠 단계마다 커밋해요.
- 내일 시연에 쓰는 그림이에요. 같은 시간에 다른 Codex 창이 C21(시연 준비, `src/**` 코드)을 해요. 이 작업은 그림만 고쳐서 파일이 겹치지 않아요.
- 가게 안의 벽·바닥·창문·스탠드·화분·문 매트는 C13 공방 그림을 그대로 같이 써요.
- 놀이 창의 과일 그림(예시 카드·시험 바구니)은 코드가 16×16 픽셀로 그려요(`src/minigames/fruit/fruitArt.ts`). 이번에 그리지 않아요.

## 공통 규칙
- **팔레트**: 64색이 가득 찼어요. 지금 색만 써요. 모자라면 가까운 색으로 그리고 진행 기록에 적어요.
- **원본**: 2배 원본은 `assets-src/hires/<kind>/<key>.txt`예요. 원본이 아직 없는 키는 `npm run assets`가 건너뛰어요(게임은 임시 그림). 그래서 단계마다 그린 키만으로도 통과해요.
- **규격**: 크기는 정확히 목록 × 2, 발은 아래 가운데에서 4px 위, 반투명 픽셀 없음, 발밑 그림자 없음(게임이 그려요).
- **스타일**
  - C11~C19처럼 빛은 왼쪽 위, 바깥 외곽선, 재질마다 3~4단 명암이에요.
  - 과일 가게는 다른 마을 건물(공방 분홍, 택배소 파랑, 불빛 가게 보라, 지도방 초록, 빵집 빨강)과 한눈에 구별돼요. 주황 지붕과 초록·흰 줄무늬 차양이 좋아요.
- 실제 가게·과일 브랜드의 로고나 글자를 그리지 않아요. **돈·동전·가격표도 그리지 않아요**(놀이는 예시 카드로만 해요).

### 1단계: 가게 건물과 방 소품

#### `prop-fruit-shop`(마을에 서 있는 과일 가게 겉모습)
- C11 `prop-house`, C13~C15 건물, C18 `prop-route-house`, C19 `prop-bakery`와 같은 크기·시점·지붕 방식이에요.
- 주황 지붕, 처마의 초록·흰 줄무늬 차양, 문 위 과일 간판(글자 없이 사과 그림), 문 옆 과일 바구니를 그려요.
- 프레임 0은 문이 닫히고 불이 꺼진 모습, 프레임 1은 문이 열리고 창에 불이 켜진 모습이에요.
- 가게는 처음부터 열려 있어서 게임은 늘 프레임 1을 보여 주고, 문 쪽에 금빛을 더해요.

#### `prop-fruit-ai`(가게 안 놀이 기계, 칸 하나)
- 받침에 고정된 과일 학습 로봇이에요. 둥근 머리에 큰 카메라 눈 하나, 가슴에 작은 화면, 앞쪽에 예시 카드가 꽂힌 나무 학습 상자가 있어요.
- 플레이어를 따라다니는 로비와 헷갈리지 않게, 바퀴·팔 없는 기계 모습으로 그려요. 기존 게임이나 제품의 로봇을 닮지 않게 해요.
- 프레임 0·1은 눈과 가슴 화면 불빛이 번갈아 밝아져요. 게임이 0.7초마다 바꾸고, 눈 높이에 청록 빛을 더해요.

#### `prop-fruit-crate`(왼쪽 벽 앞에 놓는 작은 나무 상자)
- 바닥에 바로 놓이니 상자 바닥이 발 기준점에 닿아요. C15 `prop-light-frame`, C18 `prop-route-map`, C19 `prop-cake-stand`와 같은 크기·자리 방식이에요.
- 프레임 0은 빈 나무 상자예요.
- 프레임 1~6은 판마다 그 판의 과일이 상자 위로 소복이 담긴 모습이에요. `CRATE_FRUITS`와 같아야 하고, **과일 색은 `fruitArt.ts`의 색과 같아야** 해요.
  1. 빨간 사과 · 노란 바나나
  2. 보라 포도 · 빨간 사과
  3. 귤 · 초록 사과
  4. 수박(짙은 줄무늬) · 청포도
  5. 노란 사과 · 레몬
  6. 빨간 사과 · 초록 사과 · 노란 사과
  - 작은 그림이어도 과일 종류와 색이 바로 보여야 해요. 글자·숫자는 쓰지 않아요.

#### `prop-fruit-stand`
사과·바나나·포도 바구니가 놓인 나무 매대예요(장식).

### 2단계: 놀이 아이콘
- **`icon-fruit`**: 작은 과일 바구니 아이콘이에요(빨간 사과와 노란 바나나가 담긴 나무 바구니).
- 판 고르기 카드(48px)와 '로봇 생각' 표시(32px)에 써요.
- 어두운 창(#262c3b)과 크림색 바탕 위에서 모두 또렷하게, 바깥 외곽선을 짙게 해요.

### 3단계: 물결 따라가기 카드 다듬기
- C18의 **`icon-card-followWave`**는 작은 숫자(3→2)가 블록 화면의 28px 크기에서 거의 읽히지 않아요.
- 숫자를 빼고 **물결 고리 두 겹과 굵은 화살표**로 다시 그려요. 카드 바탕색과 크기는 그대로예요.
- 옆에 놓이는 다른 블록 카드(화살표, 앞으로, 돌기)와 헷갈리지 않아야 해요.
- 검토판 `compare-20-3.png`에는 지금 그림과 새 그림을 28px·56px로 나란히 보여 줘요. `draw-c18-2-card.mjs`는 고치지 말고 새 도구로 원본을 바꾸고, 진행 기록에 적어요.

## 단계마다 할 일
1. 그 단계의 2배 원본을 그려요.
2. `npm run assets && npm test && npm run build`가 통과해야 해요.
3. 검토판 `assets-preview/compare-20-<단계 번호>.png`를 만들어요(커밋되지 않아요).
   - **왼쪽 임시 그림 / 오른쪽 새 그림**으로 나란히 보여 줘요.
   - 1단계는 가게 미리보기도 넣어요(`fruitshop` 맵 배치대로, 상자는 빈 상자·과일 상자 둘 다).
   - 1단계는 상자 1~6프레임 옆에 게임 속 과일 그림(`fruitPixels`)을 나란히 놓아 종류·색이 같은지 보여 줘요.
   - 2단계는 아이콘을 어두운 창·크림 바탕 위 48px·32px로 보여 줘요.
   - 3단계는 위 "3단계"에 적은 대로 보여 줘요.
4. 진행 기록 `docs/tasks/codex-20-progress.md`에 결과를 적어요(아래 형식).
5. 사용자가 단계마다 커밋하라고 했으면 작업 브랜치 `codex/20-fruitshop`에 커밋 하나를 해요.
   - 메시지는 `C20-<단계>: <이름>`이에요(예: `C20-1: 과일 가게 건물과 방 소품 2배 그림`).
   - main·push·머지·브랜치 바꾸기는 하지 않아요.

중간에 멈췄다가 다시 시작하면 진행 기록을 먼저 읽고 끝나지 않은 단계부터 이어서 해요.

## 게임에서 보기(포트 5176만 써요)
- `npm run dev -- --port 5176 --strictPort`로 켜요. **5173은 쓰지 않아요**(사용자의 저장 기록이 있어요). 다 쓰면 개발 서버를 꺼 주세요.
- 그림만 볼 때: `http://localhost:5176/?gallery`
- 가게 안
  1. 첫 화면 → "이 기기에서 체험" → 새 별명으로 시작해요.
  2. 과일 가게는 마을 빵집 오른쪽 집이에요. 처음부터 열려 있어요. 학습 로봇 옆에서 Space를 누르면 놀이 창이 열려요.
     - 바로 가려면 브라우저 콘솔에 `__app.game.scene.getScene('World').scene.restart({ map: 'fruitshop' })`를 입력해요.
  3. 3~6판까지 열려면 콘솔에 `__app.state.data.robiParts.push('learningChip', 'predictModule', 'ethicsCore')`를 입력해요(5176의 이 기기 저장에만 남아요).
  4. 과일이 담긴 상자를 보려면 판을 성공하거나 `__app.state.setFlag('fruit:r6')`처럼 입력한 뒤 가게에 다시 들어가요.
