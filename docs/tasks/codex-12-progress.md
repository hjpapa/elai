## 검토판과 재생성

- `npm run assets`로 PNG·아틀라스·기본 검토판을 만들어요.
- `node assets-src/tools/preview-c12.mjs N`으로 단계 N의 `assets-preview/compare-N.png`와 나눠진 `compare-N-part-*.png`를 만들어요. 모든 프레임을 옛 그림 ×4 / 새 그림 ×2로 비교해요.
- 1·3~9단계는 누적 모자×도구 조합과 로비 부품의 앞뒤 10프레임·좌우 반전 `overlays.png`를 만들어요. 단계별 사본은 `overlays-N.png`예요. 로비 부품끼리 불투명 픽셀이 겹치면 검사에 실패해요.
- 검토판은 Git에서 제외되어 있어요. 작성 도구와 텍스트 원본은 커밋해요.
- 갤러리는 `http://localhost:5173/?gallery`에서 확인해요. 브라우저 검사는 전체 186키·515프레임의 실제 텍스처 치수, 이미지 표시 크기와 배치 기준점을 비교해요. 전 장 실제 플레이 검증은 이번 그림 작업의 범위가 아니에요.

## 전체 완료와 검토 범위

- 아홉 단계를 차례로 마쳤어요. **기존 1배 148키를 2배로 전환하고 C11 발자국 1키를 다시 그렸어요. 미완료 키는 없어요.** 전체 186키·515프레임이 2배이며 팔레트는 기존 64색 그대로예요.
- 아틀라스는 2048×2048 한 장이에요. `compare-1.png`~`compare-9.png` 모두 있고, 1·3~9단계의 누적 합성판 사본도 모두 있어요. 마지막 `overlays.png`와 `robi-9.png`는 로비 8부품을 모두 포함해요.
- 모든 단계에서 `npm run assets`, `npm test`(19개 파일·201개 테스트), `npm run build`, 갤러리 치수/기준점/콘솔 확인을 통과했어요. 브라우저 검사는 실제 게임의 전체 장 진행이나 전투 효과의 체감 평가를 대신하지 않아요.
- 추가 팔레트 색은 필수가 아니에요. 1단계 포털에 중간 보라색이 있으면 명암을 더 부드럽게 만들 수 있다는 선택 의견만 있어요.
- Claude 연결 작업: 각 단계의 **소품 20종 표**를 기준으로 `shadow.ts`/`light.ts`를 갱신해 주세요. 새 그림에는 발밑 그림자가 없으므로 폭이 적힌 소품의 그림자 등록이 필요해요. 빛이 있는 소품은 표의 높이/반지름/프레임을 쓰고, 청록 광원이나 프레임별 색/높이 전환은 별도 엔진 지원이 필요해요. 신호등 외부 광원은 선택 사항이에요.
- 허용된 그림 원본·도구·생성 결과·이 진행 기록만 변경했어요. 옛 1배 원본, `palette.json`, `src/**`, `tests/**`, 계약·설정·의존성 파일은 그대로예요. 작업 브랜치에서 단계별 한 커밋으로 남기며 push·머지·main 수정은 하지 않아요.
