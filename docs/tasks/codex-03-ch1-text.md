# Codex 작업 C3 — 1장 학생용 글 다듬기·채우기

## 목표
0장·1장에서 학생이 읽는 글(아이템 설명, 도감, NPC 대사, 표지판, 미션 안내)을 더 재미있고 친절하게 다듬고 채워요. 게임 구조·정답·보상은 바꾸지 않아요.

## 먼저 읽을 것
1. `AGENTS.md`의 **콘텐츠 톤** 규칙(가장 중요해요)
2. `docs/curriculum.md`의 1장 학습 목표
3. 아래 "고쳐도 되는 파일"과 `src/data/schema.ts`(필드 뜻)

## 고쳐도 되는 파일과 필드
| 파일 | 고쳐도 되는 것 |
|---|---|
| `src/data/rpg/items.ts` | 각 아이템의 `desc` |
| `src/data/rpg/mobs.ts` | 각 몹의 `dex`, `purified` |
| `src/data/maps/village.ts`, `src/data/maps/forest.ts` | NPC의 `talk`(2~4줄, 돌아가며 말해요), 표지판 `text` |
| `src/data/chapters/ch0.ts`, `src/data/chapters/ch1.ts` | 대화 미션의 `lines`(줄을 더해도 돼요), 미션의 `intro`·`hint`·`explain`, 퀴즈 문항의 `explain` |

바꾸지 않는 것: id, 좌표, 미션 순서, 블록 퍼즐 `grid`·`palette`·`optimal`·`initialProgram`, 순서 미션의 `steps`(정답 순서), 퀴즈의 `q`·`choices`·`answer`, 설명하기 문장의 정답, 보상, 몹 능력치, 그 밖의 모든 파일.

## 할 일
1. **아이템 설명**(16개): 쓰임새가 바로 보이게 2줄 이내로 써요. 학습 도우미(디버그 안경, 순서도 지도)는 언제 어떻게 도와주는지 분명히 써요.
2. **도감**: 몹마다 성격과 행동 힌트(예: "번개를 모은 다음 세게 부딪혀요")를 넣어 전투 계획에 도움이 되게 해요. 정화 뒤 대사는 친구가 된 느낌이 나게 써요.
3. **NPC 잡담**: 촌장·요리사·숲지기·젠·허수아비 봇의 `talk`를 2~4줄로 채워요. 섬 이야기와 1장 개념(순서, 알고리즘, 디버깅)을 자연스럽게 섞어요.
4. **미션 안내**: `intro`·`hint`·`explain`이 3~4학년에게 쉽고, 한 말풍선에 2줄(한 줄 약 20자) 이내인지 확인하고 다듬어요. `\n`으로 줄을 나눠요.
5. **대화 미션 줄 늘리기**(선택): 0장 대화(`ch0-m1`, `ch0-m2`, `ch0-m4`)에 세계관을 한두 줄 더할 수 있어요. 너무 길어지지 않게 미션마다 6줄 이내로 해요.

## 톤 체크리스트
- 해요체, 말풍선 2줄 이내, 0~3장은 쉬운 낱말. 어려운 말은 뜻과 함께: "알고리즘(문제를 푸는 순서)"
- 비폭력: "죽이다, 처치, 피" 같은 말을 쓰지 않아요. 몹은 고쳐 주거나 정화해서 친구가 돼요.
- 실존 인물·브랜드·기존 게임 이름을 쓰지 않아요. 성별·외모 고정관념이 없게 해요.
- 학생 개인정보를 묻거나 넣게 하지 않아요.

- 바꾼 글이 위 체크리스트를 모두 지켜요.
