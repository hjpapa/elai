# Codex 작업 C14 — 마을 택배소와 코딩 택배 분류 그림

## 목표
2.5D 개선 4단계의 두 번째 건물이에요. 엔진은 Claude가 먼저 만들었고, 지금은 임시 그림으로 끝까지 돌아가요.
- 마을 광장 오른쪽 위 집(16,7)이 **마을 택배소**예요.
  - 1장을 끝내 마을이 고쳐지기 전(`village-restore-1` 전)에는 낡고 닫힌 모습이에요.
  - 고쳐지면 문이 열리고, 걸어 들어가면 실내 맵 `parcel`로 가요.
- 택배소 안 분류 기계에서 **코딩 택배 분류** 6판을 해요.
  - 컨베이어로 오는 물건(하트 상자·별 상자·공)을 '왼쪽으로 보내기'·'오른쪽으로 보내기' 블록으로 바구니에 나눠요.
  - 순서(1장) → 반복(2장) → 만약(3장) 차례로 블록이 늘어요. 운이나 코인은 없어요.
- 판을 처음 성공하면 배달 도장을 받고, 택배소 왼쪽 벽 앞에 보낸 상자 더미가 하나씩 쌓여요.

이번 작업은 **새 그림 11개(모두 2배)**와 C13 검토에서 남은 **동굴 벽 윗면 다듬기**예요. 세 단계로 나눠 단계마다 커밋해요.
택배소 안의 벽·바닥·창문·화분·스탠드·문 매트는 C13 공방 그림을 그대로 같이 써요.

## 공통 규칙
- **팔레트**: 64색이 가득 찼어요. 지금 색만 써요. 모자라면 가까운 색으로 그리고 진행 기록에 적어요.
- **원본**: 2배 원본은 `assets-src/hires/<kind>/<key>.txt`예요. 원본이 아직 없는 키는 `npm run assets`가 건너뛰어요(게임은 임시 그림). 그래서 단계마다 그린 키만으로도 통과해요.
- **규격**: 크기는 정확히 목록 × 2, 발은 아래 가운데에서 4px 위, 반투명 픽셀 없음, 발밑 그림자 없음(게임이 그려요).
- **스타일**: C11~C13처럼 빛은 왼쪽 위, 바깥 외곽선, 재질마다 3~4단 명암이에요. 택배소는 공방 옆에 서는 마을 건물이라 같은 마을로 보이게 하되, 한눈에 다른 건물로 구별돼요.
- **물건 구별**: 하트 상자·별 상자·공은 색만이 아니라 **그림(하트·별)과 모양(네모·둥근)으로도** 구별돼야 해요(색약 학생 배려).
- 실제 택배 회사·브랜드의 로고·글자를 그리지 않아요. **돈·동전 표시도 그리지 않아요**(놀이는 프로그램으로만 해요).

## 단계(차례대로 해요)
| 단계 | 이름 | 키(2배 PNG 크기) |
|---|---|---|
| 1 | 택배소 건물과 방 소품(4) | `prop-parcel-office` 128×96(2프레임), `prop-sorter` 128×96(2프레임), `prop-parcel-stack` 64×48(2프레임), `prop-parcel-pile` 64×64 |
| 2 | 놀이 판 그림(7) | `prop-sort-basket` 64×32(2프레임), `icon-sort-heart`, `icon-sort-star`, `icon-sort-ball`, `icon-card-sendLeft`, `icon-card-sendRight`, `icon-stamp` 모두 32×32 |
| 3 | 동굴 벽 윗면 다듬기(C13 검토) | `block-cave` 64×48 다시 그리기 |

### 1단계: 택배소 건물과 방 소품
- **`prop-parcel-office`**(마을에 서 있는 택배소 겉모습): C11 `prop-house`, C13 `prop-workshop`과 같은 크기·시점·지붕 방식이에요.
  - 문 위에 상자 그림 간판을 달아 한눈에 택배소로 보여요(파란 지붕 등 공방과 다른 색).
  - 프레임 0은 마을이 고쳐지기 전의 낡고 닫힌 모습이에요(옛 `prop-house` 프레임 0처럼 바랜 색, 닫힌 문).
  - 프레임 1은 고쳐진 모습이에요. 문이 열리고 창에 불빛이 비쳐요.
  - 게임은 마을이 고쳐지면 프레임 1을 보여 주고, 문 쪽에 금빛을 더해요.
- **`prop-sorter`**(택배소 안 놀이 기계, 칸 하나): 뒤쪽 투입구에서 벨트가 내려와 가운데 문에서 왼쪽·오른쪽 바구니로 갈라지는 친근한 기계예요.
  - 몸체는 놀이 창과 같은 청록이에요.
  - 프레임 0·1은 벨트 줄무늬가 한 칸 움직이고 작은 불빛이 번갈아 켜져요. 게임이 0.7초마다 바꾸고, 위쪽에 청록 빛 무리를 더해요.
- **`prop-parcel-stack`**: 판을 성공할 때마다 왼쪽 벽 앞에 하나씩 놓이는 "보낸 상자 더미"예요.
  - 2~3개를 쌓은 작은 상자들이고, 프레임 0은 하트 스티커 빨간 상자 위주, 프레임 1은 별 스티커 파란 상자 위주예요.
  - 바닥에 바로 놓이니 맨 아래 상자 밑면이 발 기준점에 닿아요.
- **`prop-parcel-pile`**: 입구 옆에 쌓인 갈색 택배 상자 더미(장식)예요. 테이프·주소 칸 같은 잔무늬는 넣되 글자는 쓰지 않아요.

### 2단계: 놀이 판 그림
놀이 창에서는 기울인 판 위에 세워서 40~60px로 커져요. 어두운 기계 판(연회색 칸, 줄무늬 벨트) 위에서 또렷하게 보여야 해요.
- **`prop-sort-basket`**: 엮은 바구니예요. 프레임 0은 비어 있고, 프레임 1은 물건이 조금 담겨 있어요.
- **`icon-sort-heart`, `icon-sort-star`**: 위에서 살짝 내려다본 작은 상자예요.
  - 하트는 빨간 상자에 흰 하트 스티커, 별은 파란 상자에 노란 별 스티커예요.
  - 두 상자는 모양이 같고 색과 스티커만 달라요.
- **`icon-sort-ball`**: 노란 공이에요. 상자와 달리 확실히 둥글어야 해요(6판 "둥근 물건이라면"의 답이에요).
- **`icon-card-sendLeft`, `icon-card-sendRight`**: 보내기 블록 카드예요. 다른 `icon-card-*`와 크기·선 두께·여백을 맞추고, 상자 하나와 왼쪽/오른쪽 화살표를 그려요(블록 색은 청록이에요).
- **`icon-stamp`**: 배달 도장이에요. 둥근 도장 자국 안에 상자 무늬가 있어요.
  - 도장판에서는 받기 전엔 회색으로, 받으면 원래 색으로 보여요.
  - 결과 창에서는 96px로 커져요.

### 3단계: 동굴 벽 윗면 다듬기(C13 검토에서 남은 점)
- C13에서 `tile-cave`를 차분하게 다시 그렸지만, `block-cave` 윗면에는 옛 판돌·광물 무늬가 남아 새 바닥보다 바빠 보여요.
- 윗면의 무늬 대비를 낮추고 광물 점을 줄여 새 바닥과 어울리게 해요. 옆면(바위벽)의 느낌과 크기·기준점은 그대로예요.
- C12 그림 도구를 다시 돌리면 동굴 그림이 옛 모습으로 돌아가요. 3단계 도구는 C13 동굴 도구처럼 따로 두고, 다시 그릴 때 마지막에 돌리도록 진행 기록에 적어요.

## 단계마다 할 일
1. 그 단계의 2배 원본을 그려요.
2. `npm run assets && npm test && npm run build`가 통과해야 해요.
3. 검토판 `assets-preview/compare-14-<단계 번호>.png`를 만들어요(커밋되지 않아요).
   - **왼쪽 임시 그림 / 오른쪽 새 그림**으로 나란히 보여 줘요. 3단계는 옛 `block-cave` / 새 `block-cave`예요.
   - 1단계는 택배소 방 미리보기(`parcel` 맵 배치대로)도 넣어요.
   - 3단계는 새 동굴 바닥과 이어 깐 모습도 넣어요.
4. 진행 기록 `docs/tasks/codex-14-progress.md`에 결과를 적어요(아래 형식).
5. 사용자가 단계마다 커밋하라고 했으면 작업 브랜치 `codex/14-parcel`에 커밋 하나를 해요.
   - 메시지는 `C14-<단계>: <이름>`이에요(예: `C14-1: 택배소 건물과 방 소품 2배 그림`).
   - main·push·머지·브랜치 바꾸기는 하지 않아요.

중간에 멈췄다가 다시 시작하면 진행 기록을 먼저 읽고 끝나지 않은 단계부터 이어서 해요.

## 게임에서 보기(포트 5176만 써요)
- `npm run dev -- --port 5176 --strictPort`로 켜요. **5173은 쓰지 않아요**(사용자의 저장 기록이 있어요).
- 그림만 볼 때: `http://localhost:5176/?gallery`
- 택배소 안:
  1. 첫 화면 → "이 기기에서 체험" → 새 별명으로 시작해요.
  2. 개발 서버에서는 브라우저 콘솔에 `__app.state.setFlag('village-restore-1')`을 입력하면 마을이 고쳐져 택배소 문이 열려요(5176의 이 기기 저장에만 남아요).
  3. 3~6판까지 열려면 `__app.state.data.robiParts.push('memoryChip', 'sensor')`도 입력해요.
- 택배소는 마을 광장 오른쪽 위, 공방 왼쪽 집이에요. 분류 기계 옆에서 Space를 누르면 놀이 창이 열려요.
