# C25 프롬프트 공방 진행 기록

## 1단계 · 앞말 수와 젠의 세 답 비교

한 글 모음에 탐험과 꿈 기록을 넣었어요. ‘로비는 동굴에서 수정을 먹어요.’는 앞말 하나에서만 이어져요. 시연 메뉴에서 1366·390·320px로 두 탭을 모두 풀었고 미완성 제출 안내 뒤 별 2개를 받았어요. 테스트 486개와 빌드 통과.

## 2단계 · 두 글 주문서의 기준표

양치 의뢰에 조건 4개와 함정 2개, 도서관 의뢰에 조건 3개와 함정 2개를 추가했어요. 기존 데이터·보상 해시를 포함한 488개 테스트와 빌드 통과. 세 화면 크기의 시연 메뉴에서 함정 피드백, 예상·확인, 빈 자기 확인 거절, 판정 비교를 거쳐 두 미션 모두 별 3개를 확인했어요.

## 3단계 · 답에서 원인을 찾아 고쳐 묻기

가려진 주문서는 책장 지킴이·공동 책장 약속·어려운 말·한 문단이에요. 문제 칸은 말의 난이도와 모양이에요. 막연하게 다시 쓰거나 시로 바꿔도 완료되지 않고, 쉬운 말과 세 줄 목록을 구체적으로 부탁해야 풀렸어요. 세 화면 크기에서 원인 찾기 1·2·3회에 별 3·2·1개를 확인했고 고쳐 묻기 네 번은 별에 영향을 주지 않았어요. 489개 테스트·빌드 통과.
