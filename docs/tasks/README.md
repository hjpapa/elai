# Codex 작업 지시서

Claude가 지시서를 쓰고, 사용자가 Codex 앱에서 실행해요.

## 실행 방법
1. Claude가 알려 준 작업 폴더(예: `C:\code\elai-wt\codex-01`)를 Codex 앱에서 열어요. 브랜치와 `npm install`은 Claude가 미리 준비해 둬요.
2. 원하는 모델을 고르고 이렇게 부탁해요.
   > `docs/tasks/codex-01-assets.md` 지시서대로 작업해 줘. `AGENTS.md` 규칙을 지켜 줘.
3. Codex가 끝나면 Claude에게 "C1 끝났어"처럼 알려 주세요. Claude가 검토하고, 테스트한 뒤 커밋·머지해요.

### 마을 택배소 그림(C14, 완료)
Codex 앱에서 `C:\code\elai-wt\codex-14`(브랜치 `codex/14-parcel`)를 열고 이렇게 부탁해요. 중간에 멈추면 같은 말을 다시 하면 진행 기록(`codex-14-progress.md`)을 보고 이어서 해요.
> `docs/tasks/codex-14-parcel.md`대로 1단계부터 차례로 진행하고, 단계마다 커밋해 줘. `AGENTS.md` 규칙을 지켜 줘.

몇 단계만 끝나도 Claude에게 "C14 1단계 끝났어"처럼 알려 주면 커밋 단위로 검토해서 main에 머지해요.

> `docs/tasks/codex-13-workshop.md`대로 1단계부터 차례로 진행하고, 단계마다 커밋해 줘. `AGENTS.md` 규칙을 지켜 줘.

몇 단계만 끝나도 Claude에게 "C13 1단계 끝났어"처럼 알려 주면 커밋 단위로 검토해서 main에 머지해요.

### 할당량 절약 기간(C4~C10)
**한 번에 맡기기**: Codex 앱에서 `C:\code\elai-wt\codex-04`를 열고 이렇게만 부탁해요. 중간에 멈추면 같은 말을 다시 하면 이어서 해요.
> `docs/tasks/codex-run-all.md`대로 C4부터 C10까지 끝까지 진행해 줘. `AGENTS.md` 규칙을 지켜 줘.

**단계마다 맡기기**(Codex가 쓴 지시서를 중간에 보고 싶을 때):
1. Codex 앱에서 `C:\code\elai-wt\codex-04`(브랜치 `codex/04-chapters`)를 열고 이렇게 부탁해요.
   > `docs/tasks/codex-04-ch2.md` 지시서대로 작업해 줘. `AGENTS.md` 규칙을 지켜 줘.
2. 끝나면 최종 보고를 보고, 다음 단계로 넘어가요.
   > 지금 작업을 C4로 커밋해 줘. 그다음 `docs/tasks/codex-roadmap.md`의 C5를 진행해 줘.
3. C10까지 같은 폴더에서 이어 가요. Claude 할당량이 차면 "C4~C7 끝났어, 검토해 줘"처럼 알려 주세요. Claude가 커밋 단위로 검토해서 main에 머지해요.

- 1단계 엔진은 끝났어요(2026-11-06): 길 안내, 터치 조이스틱·행동 단추·말하기 안내, 회전 블록(1장 '빠진 돌기 블록', 2장 '네모 벽화'), 2.5D 퍼즐 판.
- 2단계 엔진(2026-11-06):
  - 화면 배율: 캔버스를 기기 픽셀 크기로 만들고(화면 배율 125%·150%·레티나), 카메라 배율은 짝수만 써서 2배 그림 한 픽셀이 화면 픽셀 정수 개예요(`src/game/screen.ts`). 1366×768 노트북은 예전보다 넓게(배율 2) 보여요.
  - 발밑 그림자: 2배 그림의 캐릭터·몹·소품 아래 반투명 타원(`src/game/shadow.ts`). 옛 1배 그림은 그림 안의 그림자를 그대로 써요.
  - 등불 빛: 가로등 머리의 빛 무리와 바닥 빛 웅덩이, 살짝 일렁여요(`src/game/light.ts`).
  - 섬 가장자리 땅 두께: 탐험 맵·첫 화면 섬의 아래쪽 두 변에 흙·물·돌 옆면(`src/game/iso/edges.ts`). 안개 미로에는 그리지 않아요.
  - 화면 테두리: 창·단추·대화창·HUD·알림·조이스틱에 ui 그림을 입혀요(`src/ui/skin.ts`). 어두운 창과 색 단추는 종이 색만 바꾼 판을 써서 글자 색은 그대로예요.
  - 남은 일이던 시간대 빛, 칸·막대 테두리, 걸어 올라가는 높낮이(언덕·계단)는 아래 "2단계 남은 엔진"에서 했어요.
  - 소품 그림자·불빛 목록은 C12 진행 기록의 표대로 채웠어요(아래 C12).
- C11 마을 시범 그림은 main에 병합했어요(2026-11-06). 검토에서 나온 점:
  - 길 안내 발자국(`icon-path-step`)이 흙길 위에서 잘 안 보였어요(금색 위 금색). C12에서 짙은 외곽선의 크림색 발자국으로 고쳤어요.
  - 화면 배율이 3이면 2배 그림 한 픽셀이 1.5픽셀로 그려져 고르지 않았어요. 2단계 화면 배율로 고쳤어요(짝수 배율).
  - 화면 테두리(ui) 바깥선은 남색, 안쪽 띠는 금갈색이에요. 어두운 창에 입혀 보니 어울려서 그대로 써요.
  - 다른 장 그림이 1배라 마을 그림과 섞이면 거칠어 보였어요. C12에서 모두 2배로 바꿨어요.
- C12 장별 2배 그림은 main에 병합했어요(2026-11-07). 이제 186개 그림이 모두 2배이고 아틀라스는 2048×2048 한 장이에요.
  - 검토: 범위·팔레트·옛 1배 원본 그대로, 크기 정확히 2배, 바닥 마름모·블록 모양·발 기준선 일치, 로비 부품 8개 겹침 없음(얼굴 화면 보임). 숲·동굴·사막·항구·연구소·천문대·공방·성 맵과 보스 전투를 브라우저에서 확인했어요.
  - 엔진 연결: 소품 13종 발밑 그림자, 불빛(별 등불·부표 금색, 켜진 등대만, 반짝이는 수정과 이동 문은 청록). 불빛에 켜지는 프레임과 색을 고를 수 있게 했어요. 신호등은 렌즈가 이미 밝아서 빛을 더하지 않았어요(진행 기록에서도 선택 사항).
  - 고친 버그: 물 타일 물결과 기본 이동 문 반짝임이 움직이지 않았어요. 프레임 이름이 숫자인데 글자 '0'과 비교하고 있었어요.
  - 나중에 다듬을 점: 동굴 바닥은 칸마다 같은 판돌·광물 점이라 크게 보면 격자가 눈에 띄어요(더 차분하게 → C13 4단계). 천문대 별자리 바닥은 카펫처럼 반복돼도 괜찮아요. 로비 부품 8개를 모두 달면 머리 위 하트·별·말풍선이 나란히 붙어 조금 붐벼요.
- 4단계 엔진(2026-11-07): 마을 공방과 코딩 인형뽑기. 설계는 사용자와 정했어요.
  - **들어가는 건물**:
    - 마을 공방 집 칸이 문(portal, 그림 `prop-workshop`)이에요. 걸어 들어가면 실내 맵 `workroom`(10×8)으로 가요. 뒤쪽 두 변만 높은 벽(`block-room-wall`·`-window`, 32×56)이고, 앞쪽은 나무 바닥 두께가 보여요.
    - 앞 가장자리 문 매트를 밟으면 공방 문 앞으로 나와요. 건물 안 문의 행동 단추는 '나가기'예요.
    - 길찾기(누른 곳으로 걷기·길 안내)는 목표가 아닌 문 칸을 피해요. 그래서 지나가다 건물에 들어가지 않아요.
  - **미니게임 틀**(`src/minigames/`):
    - 맵 오브젝트 `type: 'game'`(놀이 기계)이 창을 열어요.
    - 판별 가장 좋은 별은 저장 데이터 `minigames`에, 판 보상은 플래그·칭호로 남아요.
    - 장 진도·교사 진도표·경험치·동전에는 영향이 없어요(성장 곡선 그대로).
  - **코딩 인형뽑기 6판**(`src/data/minigames/claw.ts`):
    - 블록이 배운 차례로 늘어요. 1~2판은 화살표, 3~4판은 앞으로·돌기(1장 '빠진 돌기 블록' 또는 바퀴 모터), 5~6판은 반복(2장 '긴 굴' 또는 메모리 칩)이에요. 새 블록은 '집기' 하나예요.
    - 집게는 인형 위로는 지나가고, 큰 상자·기계 벽에는 부딪혀요. 집으면 저절로 출구로 돌아와요. 다른 인형을 집으면 제자리에 내려놓아요.
    - 운·코인은 없어요. 같은 프로그램이면 늘 같은 결과예요.
    - 별은 퍼즐과 같은 블록 수 기준이에요. 반복 판은 반복을 써야 별 3개예요(테스트).
  - **보상**:
    - 판을 처음 성공하면 섬 친구 인형이 공방 방석에 앉아요(플래그 `doll:<id>`).
    - 6개를 모으면 칭호 '집게 장인'을 받아요.
  - **블록 편집기**: 실행 중인 블록을 보여 줄 때 블록 목록 안에서만 스크롤해요. 휴대폰에서 판이 화면 밖으로 밀려나지 않아요(퍼즐·전투도 같아요).
  - **임시 그림**: 끝까지 동작해요(`src/game/textures/roomPlaceholders.ts`). 진짜 그림은 C13이에요.
