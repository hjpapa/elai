# Codex 작업 지시서

Claude가 지시서를 쓰고, 사용자가 Codex 앱에서 실행해요.

## 실행 방법
1. Claude가 알려 준 작업 폴더(예: `C:\code\elai-wt\codex-01`)를 Codex 앱에서 열어요. 브랜치와 `npm install`은 Claude가 미리 준비해 둬요.
2. 원하는 모델을 고르고 이렇게 부탁해요.
   > `docs/tasks/codex-01-assets.md` 지시서대로 작업해 줘. `AGENTS.md` 규칙을 지켜 줘.
3. Codex가 끝나면 Claude에게 "C1 끝났어"처럼 알려 주세요. Claude가 검토하고, 테스트한 뒤 커밋·머지해요.

### 할당량 절약 기간(C4~C10)
**한 번에 맡기기**: Codex 앱에서 `C:\code\elai-wt\codex-04`를 열고 이렇게만 부탁해요. 중간에 멈추면 같은 말을 다시 하면 이어서 해요.
> `docs/tasks/codex-run-all.md`대로 C4부터 C10까지 끝까지 진행해 줘. `AGENTS.md` 규칙을 지켜 줘.

**단계마다 맡기기**(Codex가 쓴 지시서를 중간에 보고 싶을 때):
1. Codex 앱에서 `C:\code\elai-wt\codex-04`(브랜치 `codex/04-chapters`)를 열고 이렇게 부탁해요.
   > `docs/tasks/codex-04-ch2.md` 지시서대로 작업해 줘. `AGENTS.md` 규칙을 지켜 줘.
2. 끝나면 최종 보고를 보고, 다음 단계로 넘어가요.
   > 지금 작업을 C4로 커밋해 줘. 그다음 `docs/tasks/codex-roadmap.md`의 C5를 진행해 줘.
3. C10까지 같은 폴더에서 이어 가요. Claude 할당량이 차면 "C4~C7 끝났어, 검토해 줘"처럼 알려 주세요. Claude가 커밋 단위로 검토해서 main에 머지해요.

## 규칙
- Codex는 지시서에 적힌 파일만 고치고, 커밋·push·브랜치 변경은 하지 않아요.
- 작업 폴더는 Claude가 일하는 폴더(`C:\code\code14_elai`)와 따로라서 서로 방해하지 않아요.

## 2.5D 개선 기간(2026-11-06~) 단계와 담당
학생 테스트 의견: 코딩 미션에 회전이 없음, 조작이 아쉬움, 어디로 갈지 모름, 2.5D 느낌, 건물 안 미니게임, 그림 품질.

| 단계 | 내용 | Claude(엔진) | Codex(그림·내용) |
|---|---|---|---|
| 1 | 길 안내(목표 NPC 표시·화면 가장자리 화살표·길 안내 단추), 조작(이어 걷기·터치 조이스틱·말하기 단추), 회전 블록(1장 파트 3부터), 2.5D 퍼즐 판 | 전부 | 표시 아이콘(C11에 포함) |
| 2 | 고해상도 시범: 마을 그림 2배, 화면 테두리 | 2배 그림 읽기(완료), 발밑 그림자·빛·높낮이, 화면 테두리 입히기 | C11 |
| 3 | 시범이 좋으면 1~8장 그림을 차례로 2배로 | 검토 | 장마다 지시서 |
| 4 | 들어가는 건물(실내 맵)과 미니게임: 코딩 인형뽑기부터 | 실내 맵·미니게임 틀 | 실내·기계·인형 그림, 놀이 내용 |

- 1단계 엔진은 끝났어요(2026-11-06): 길 안내, 터치 조이스틱·행동 단추·말하기 안내, 회전 블록(1장 '빠진 돌기 블록', 2장 '네모 벽화'), 2.5D 퍼즐 판.
- 2단계 엔진에서 남은 일: 발밑 그림자, 빛(등불·시간대), 땅 높낮이, 화면 테두리(ui) 그림을 창·단추에 입히기, 2배 그림을 쓸 때의 화면 배율.
- C11 마을 시범 그림은 main에 병합했어요(2026-11-06). 검토에서 나온 점:
  - 길 안내 발자국(`icon-path-step`)이 흙길 위에서 잘 안 보여요(금색 위 금색). 다음 그림 지시서에서 고쳐요.
  - 화면 배율이 3이면 2배 그림 한 픽셀이 1.5픽셀로 그려져 고르지 않아요. 2단계 화면 배율에서 정해요.
  - 화면 테두리(ui) 색이 지시서의 짙은 남색이 아니라 갈색이에요. 창·단추에 입혀 본 뒤 정해요.
  - 다른 장 그림은 아직 1배라 마을 그림과 섞이면 거칠어 보여요. 3단계에서 장마다 2배로 바꿔요.
- 엔진은 Claude가 먼저 만들고, Claude 사용량 한도에 걸리면 남은 엔진 작업을 지시서로 넘겨요.
- 인형뽑기 같은 놀이는 **운이 아니라 프로그램대로** 결과가 정해지고, 코인을 걸고 뽑는 방식은 쓰지 않아요(처음 계획의 "확률 뽑기 없음").
