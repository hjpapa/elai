# C22 학습 콘텐츠 진행 기록

## 1단계 · 글과 사실 바로잡기

디버깅 보기의 말투, 젖 먹이기 분류 질문, 두 센서 길과 별빛 미궁의 안내를 수정했어요. 428개 테스트와 빌드 통과. 5182 시연 메뉴로 동물 맞히기를 열어 새 질문을 확인했어요.

## 2단계 · 선택 미션 진행 규칙

선택 기록이 없는 저장의 목표와 장 완료 판정, NPC 권유·청록 느낌표를 구현했어요. 시연 6장 이동 후 길 안내가 첫 필수 목표를 가리켰고, 429개 테스트와 빌드가 통과했어요. 실제 선택 데이터로 권유·무시하기는 4단계에서 확인해요.
