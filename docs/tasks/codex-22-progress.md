# C22 학습 콘텐츠 진행 기록

## 1단계 · 글과 사실 바로잡기

디버깅 보기의 말투, 젖 먹이기 분류 질문, 두 센서 길과 별빛 미궁의 안내를 수정했어요. 428개 테스트와 빌드 통과. 5182 시연 메뉴로 동물 맞히기를 열어 새 질문을 확인했어요.

## 2단계 · 선택 미션 진행 규칙

선택 기록이 없는 저장의 목표와 장 완료 판정, NPC 권유·청록 느낌표를 구현했어요. 시연 6장 이동 후 길 안내가 첫 필수 목표를 가리켰고, 429개 테스트와 빌드가 통과했어요. 실제 선택 데이터로 권유·무시하기는 4단계에서 확인해요.

## 3단계 · 5·6장 자료 비교 실험

5장 50%→100%, 6장 50·75·88·100·75%를 320px 시연 화면에서 직접 학습·시험·저장했어요. 분류 모델은 8개 표본 유지. 모든 시험 결과·정답과 최종 모델을 확인하고, 이름표를 바꾸면 이전 기록을 지워요. 소개·힌트·정리 중복 검사 포함 429개 테스트·빌드 통과.

## 4단계 · 다시 풀어 보는 선택 미션 11개

- 기존 NPC에 11개 미션을 연결했어요. 각 보상은 동전 8개예요. 블록·표본·막대·글 생성·그림 주문·원본 확인 등 기존 엔진을 사용해요.
- 자동 검사 433개 통과, 타입 검사와 빌드 통과. 두 신호를 판단하는 4블록, 돌아가는 길의 실패, 경계 표본 3/4, NPC·보상 순서도 검사했어요.
- Edge 시연 메뉴로 11개 모두 실제 입력 후 보상 확인, 완료 기록을 확인했어요. 일반 모드는 독립 브라우저에 6장 시작 기록을 준비해 천문대 필수를 완료한 뒤 ‘다음에요’를 눌렀어요. 다음 목표와 NPC의 다음 미션이 ch6-p2-m1이고 선택 미션은 미완료였어요.
- 1단계에 글을 바꾼 센서 2개·동물 나무·보스 미로도 일반/시연에서 별 3개로 완료했어요. 실제 휴대폰은 확인하지 않았어요.
