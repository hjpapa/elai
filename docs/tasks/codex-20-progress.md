# C20 과일 가게

## 1단계

건물·학습 로봇·상자·매대 4키(12프레임)를 완성했어요. 게임과 같은 fruitPixels 및 CRATE_FRUITS를 사용해 여섯 보상 조합과 색을 맞췄어요. 5176의 갤러리에서 실제 임시 그림을 추출했고, 로컬 체험 실내에서 빈 상자 여섯 개가 프레임 0이고 시험용 플래그 설정 뒤 1~6이 되는지 확인했어요. 페이지 예외 0개. 검토판은 assets-preview/compare-20-1.png예요.

| 소품 | 발밑 그림자 | 불빛 |
|---|---|---|
| prop-fruit-shop | 없음 | 아래에서 28%, 반지름 12, 열린 프레임 1, 금색 |
| prop-fruit-ai | 없음 | 아래에서 62%, 반지름 10, 두 프레임, 청록. 눈 중심은 물리 y36/96 |
| prop-fruit-crate | 없음 | 없음 |
| prop-fruit-stand | 없음 | 없음 |

그림 생성·테스트 406개·빌드 통과. 아틀라스 2048×2048 한 장, 생성한 241키 모두 2배예요. 팔레트 64색 유지. 다음 단계는 놀이 아이콘, 그다음은 기존 물결 카드예요. Claude는 4판의 초록 과일 둘을 줄무늬와 송이 모양으로 구분할 수 있는지 봐 주세요.

## 2단계

icon-fruit를 완성했어요. 나무 바구니 뒤쪽 손잡이와 바나나 사이에 공간을 남기고 사과와 바나나의 방향을 달리했어요. 실제 판 목록에서 48px, 로봇 생각에서 32px로 로드됐어요. assets-preview/compare-20-2.png에서 어두운 창과 크림색 바탕 두 크기를 확인했어요. 그림 생성·406개 테스트·빌드 통과. 2048×2048 아틀라스의 242키 모두 2배예요. 남은 것은 물결 카드 수정이에요.

## 3단계

기존 물결 카드의 숫자를 지우고 두 겹 청록색 고리와 굵은 크림색 화살표를 그렸어요. 바탕과 크기는 유지했어요. 이전 C18 도구 대신 draw-c20-3-wave.mjs가 이 카드의 최신 원본을 만들어요. assets-preview/compare-20-3.png에 변경 전후 28px·56px 및 이웃 이동 카드 3종을 함께 놓았어요.

그림 생성·테스트 406개·빌드 통과. 5176 갤러리에서 이번 6키·14프레임 전체의 2배 프레임 크기와 논리 표시 크기가 모두 일치했어요. 최종 아틀라스 2048×2048 한 장, 242키 모두 2배. 남은 그림이나 추가로 필요한 색, 범위 밖 변경은 없어요. Claude는 28px에서 고리와 화살표 방향이 앞·회전 카드와 구분되는지, 4판 수박과 청포도가 구분되는지 확인해 주세요. 실제 휴대폰 터치 및 6판 자연 진행은 이번 그림 검증에 포함하지 않았어요.
