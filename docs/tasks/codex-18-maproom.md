# Codex 작업 C18 — 마을 지도방과 코딩 길찾기 그림

## 목표
2.5D 개선 4단계의 네 번째 건물이에요. 엔진은 Claude가 먼저 만들었고, 지금은 임시 그림으로 끝까지 돌아가요.
- 마을 광장 왼쪽 아래 빈 집 자리(8,13)가 **마을 지도방**이에요.
  - 처음부터 열려 있어요. 걸어 들어가면 실내 맵 `maproom`으로 가요.
- 지도방 안 길찾기 탁자에서 **코딩 길찾기** 6판을 해요.
  - 미로에서 로봇을 깃발까지 데려가요.
  - 깃발에서 물결을 퍼뜨리면 칸마다 '깃발까지 몇 걸음'(물결 숫자)이 적혀요.
  - 5·6판은 '물결 따라가기'(숫자가 하나 작은 칸으로 한 걸음) 블록을 반복해서 가장 짧은 길로 가요(6장 물결 탐색).
  - 6판은 같은 프로그램으로 미로 세 개를 모두 풀어요. 운이나 코인은 없어요.
- 판을 처음 성공하면 지도방 왼쪽 벽 앞의 빈 미로 지도에 그 판의 길이 그려져요.

이번 작업은 **새 그림 5개(모두 2배)**예요. 두 단계로 나눠 단계마다 커밋해요.
- 지도방 안의 벽·바닥·창문·스탠드·화분·문 매트는 C13 공방 그림을 그대로 같이 써요.
- 놀이 판은 있는 그림을 그대로 써요(새로 그리지 않아요).
  - 로봇: `icon-robi`
  - 바위(벽): `icon-cell-rock`
  - 깃발: `icon-goal`

## 공통 규칙
- **팔레트**: 64색이 가득 찼어요. 지금 색만 써요. 모자라면 가까운 색으로 그리고 진행 기록에 적어요.
- **원본**: 2배 원본은 `assets-src/hires/<kind>/<key>.txt`예요. 원본이 아직 없는 키는 `npm run assets`가 건너뛰어요(게임은 임시 그림). 그래서 단계마다 그린 키만으로도 통과해요.
- **규격**: 크기는 정확히 목록 × 2, 발은 아래 가운데에서 4px 위, 반투명 픽셀 없음, 발밑 그림자 없음(게임이 그려요).
- **스타일**
  - C11~C15처럼 빛은 왼쪽 위, 바깥 외곽선, 재질마다 3~4단 명암이에요.
  - 지도방은 공방·택배소·불빛 가게와 같은 마을 건물로 보이되, 한눈에 다른 건물로 구별돼요(초록 지붕, 지도·깃발·나침반 느낌).
- 실제 지도 서비스·내비게이션·브랜드의 로고나 글자를 그리지 않아요. **돈·동전·가격표도 그리지 않아요**(놀이는 프로그램으로만 해요).

### 1단계: 지도방 건물과 방 소품

#### `prop-route-house`(마을에 서 있는 지도방 겉모습)
- C11 `prop-house`, C13 `prop-workshop`, C14 `prop-parcel-office`, C15 `prop-light-shop`과 같은 크기·시점·지붕 방식이에요.
- 문 위에 깃발이 꽂힌 지도 간판을 달아 한눈에 지도방으로 보여요. 지붕은 초록 계열로 다른 건물과 달라요.
- 프레임 0은 문이 닫히고 불이 꺼진 모습, 프레임 1은 문이 열리고 창에 불이 켜진 모습이에요.
- 지도방은 처음부터 열려 있어서 게임은 늘 프레임 1을 보여 주고, 문 쪽에 금빛을 더해요.

#### `prop-route-table`(지도방 안 놀이 기계, 칸 하나)
- 나무 탁자 위에 작은 미로 판(바위 몇 개), 작은 로봇 모형, 깃발이 놓여 있어요.
- 프레임 0·1은 깃발에서 퍼지는 물결 고리가 번갈아 작아졌다 커져요. 게임이 0.7초마다 바꾸고, 위쪽에 청록 빛 무리를 더해요.

#### `prop-route-map`(왼쪽 벽 앞에 세워 두는 작은 지도)
- 받침 다리가 있어서 바닥에 바로 놓이니 다리 끝이 발 기준점에 닿아요. C15 `prop-light-frame`과 같은 크기·자리 방식이에요.
- 프레임 0은 길이 없는 빈 지도예요(옅은 격자와 접힌 자국).
- 프레임 1~6은 판마다 첫 미로에 출발점에서 깃발까지 가장 짧은 길이 그려진 지도예요. `src/data/minigames/route.ts`의 미로와 칸 배치가 같아야 해요.
  - 아래는 `S` 출발, `G` 깃발, `#` 벽(바위), `*` 그려진 길, `.` 빈 길이에요.
    1. `S*#` / `#**` / `##G`
    2. `S***#` / `.##*#` / `.#.*G` / `...##`
    3. `S*****` / `#####*` / `G*****`
    4. `S*###` / `#**##` / `##**#` / `###*G`
    5. `S*#...` / `#*#.#.` / `#***#.` / `###*#.` / `G***..`
    6. `S**#.` / `##*#.` / `***#.` / `*###.` / `****G`
  - 길은 청록 줄로, 깃발은 빨강, 벽은 짙은 회색, 빈 길은 밝은 종이색이에요.
  - 칸 하나는 2배 그림에서 4px 안팎이에요. 미로가 크면 칸을 줄여도 되지만, 길이 이어져 보여야 해요.

#### `prop-globe`
받침대 위 지구본이에요(장식). 실제 나라 모양을 자세히 그리지 않고 둥근 땅 덩어리 몇 개로 그려요.

### 2단계: 놀이 카드
- **`icon-card-followWave`**: '물결 따라가기' 블록 카드예요.
- 다른 `icon-card-*`와 크기·선 두께·여백을 맞춰요.
- 그림: 물결 고리와, 작은 숫자 쪽을 가리키는 화살표예요.
  - 카드 바탕은 화살표 카드(파랑)·보내기 카드(청록)와 구별되는 짙은 바다색 계열이에요.
  - 편집기 블록 색은 `#1f6f8b`예요(팔레트에 없으면 가까운 팔레트 색).
- 숫자를 넣는다면 아주 작게 '3→2'처럼 줄어드는 모습만이고, 읽히지 않아도 괜찮아요.

## 단계마다 할 일
1. 그 단계의 2배 원본을 그려요.
2. `npm run assets && npm test && npm run build`가 통과해야 해요.
3. 검토판 `assets-preview/compare-18-<단계 번호>.png`를 만들어요(커밋되지 않아요).
   - **왼쪽 임시 그림 / 오른쪽 새 그림**으로 나란히 보여 줘요.
   - 1단계는 지도방 미리보기도 넣어요(`maproom` 맵 배치대로, 벽 지도는 빈 지도·그린 지도 둘 다).
   - 2단계는 블록 팔레트 색(화살표·보내기·켜기·물결 따라가기) 위에 카드들을 나란히 놓은 모습도 넣어요.
4. 진행 기록 `docs/tasks/codex-18-progress.md`에 결과를 적어요(아래 형식).
5. 사용자가 단계마다 커밋하라고 했으면 작업 브랜치 `codex/18-maproom`에 커밋 하나를 해요.
   - 메시지는 `C18-<단계>: <이름>`이에요(예: `C18-1: 지도방 건물과 방 소품 2배 그림`).
   - main·push·머지·브랜치 바꾸기는 하지 않아요.

중간에 멈췄다가 다시 시작하면 진행 기록을 먼저 읽고 끝나지 않은 단계부터 이어서 해요.

## 게임에서 보기(포트 5176만 써요)
- `npm run dev -- --port 5176 --strictPort`로 켜요. **5173은 쓰지 않아요**(사용자의 저장 기록이 있어요). 다 쓰면 개발 서버를 꺼 주세요.
- 그림만 볼 때: `http://localhost:5176/?gallery`
- 지도방 안
  1. 첫 화면 → "이 기기에서 체험" → 새 별명으로 시작해요.
  2. 지도방은 마을 광장 왼쪽 아래 집이에요. 처음부터 열려 있어요. 길찾기 탁자 옆에서 Space를 누르면 놀이 창이 열려요.
     - 바로 가려면 브라우저 콘솔에 `__app.game.scene.getScene('World').scene.restart({ map: 'maproom' })`를 입력해요.
  3. 3~6판까지 열려면 콘솔에 `__app.state.data.robiParts.push('memoryChip', 'predictModule')`을 입력해요(5176의 이 기기 저장에만 남아요).
  4. 그린 벽 지도를 보려면 판을 성공하거나 `__app.state.setFlag('route:r6')`처럼 입력한 뒤 지도방에 다시 들어가요.
