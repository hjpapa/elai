# Codex 작업 C15 — 마을 불빛 가게와 코딩 불빛 그림 그림

## 목표
2.5D 개선 4단계의 세 번째 건물이에요. 엔진은 Claude가 먼저 만들었고, 지금은 임시 그림으로 끝까지 돌아가요.
- 마을 광장 왼쪽 위 집(8,6)이 **마을 불빛 가게**예요.
  - 처음부터 열려 있어요(1장을 건너뛴 5~6학년도 들어가요). 걸어 들어가면 실내 맵 `lightshop`으로 가요.
- 가게 안 전구판 기계에서 **코딩 불빛 그림** 6판을 해요.
  - 전구판의 전구마다 숫자 판(0·1)이 붙어 있어요. 불빛 붓을 '켜기'·'앞으로'·'다음 줄' 블록으로 움직여 1인 전구만 켜요.
  - 4장 '등대 신호'(켜진 등불 = 1)와 5장 '픽셀 돋보기'(1인 칸을 켜서 그림)를 프로그램으로 이어요.
  - 5·6판은 숫자만 다른 그림 세 장을 같은 프로그램으로 켜요(같은 프로그램 + 다른 숫자 = 다른 그림). 운이나 코인은 없어요.
- 판을 처음 성공하면 가게 왼쪽 벽 앞의 불 꺼진 액자에 그 판의 그림이 켜져요.

이번 작업은 **새 그림 9개(모두 2배)**예요. 두 단계로 나눠 단계마다 커밋해요.
가게 안의 벽·바닥·창문·화분·스탠드·문 매트는 C13 공방 그림을 그대로 같이 써요.

## 공통 규칙
- **팔레트**: 64색이 가득 찼어요. 지금 색만 써요. 모자라면 가까운 색으로 그리고 진행 기록에 적어요.
- **원본**: 2배 원본은 `assets-src/hires/<kind>/<key>.txt`예요. 원본이 아직 없는 키는 `npm run assets`가 건너뛰어요(게임은 임시 그림). 그래서 단계마다 그린 키만으로도 통과해요.
- **규격**: 크기는 정확히 목록 × 2, 발은 아래 가운데에서 4px 위, 반투명 픽셀 없음, 발밑 그림자 없음(게임이 그려요).
- **스타일**: C11~C14처럼 빛은 왼쪽 위, 바깥 외곽선, 재질마다 3~4단 명암이에요. 불빛 가게는 공방·택배소와 같은 마을 건물로 보이되, 한눈에 다른 건물로 구별돼요.
- **켜짐과 꺼짐**: 켜진 전구와 꺼진 전구는 색만이 아니라 **밝기와 빛 테두리(반짝임)로도** 구별돼야 해요(색약 학생 배려).
- 실제 전등 회사·브랜드의 로고·글자를 그리지 않아요. **돈·동전·가격표도 그리지 않아요**(놀이는 프로그램으로만 해요).

## 단계(차례대로 해요)
| 단계 | 이름 | 키(2배 PNG 크기) |
|---|---|---|
| 1 | 가게 건물과 방 소품(4) | `prop-light-shop` 128×96(2프레임), `prop-lightboard` 128×96(2프레임), `prop-light-frame` 224×48(7프레임), `prop-lamp-shelf` 128×64(2프레임) |
| 2 | 놀이 판 그림(5) | `icon-bulb-off`, `icon-bulb-on`, `icon-light-brush`, `icon-card-lightOn`, `icon-card-nextRow` 모두 32×32 |

### 1단계: 가게 건물과 방 소품
- **`prop-light-shop`**(마을에 서 있는 가게 겉모습): C11 `prop-house`, C13 `prop-workshop`, C14 `prop-parcel-office`와 같은 크기·시점·지붕 방식이에요.
  - 문 위에 전구 모양 간판을 달고, 처마에 작은 알전구 줄을 걸어 한눈에 불빛 가게로 보여요(보라·남색 지붕 등 공방·택배소와 다른 색).
  - 프레임 0은 문이 닫히고 불이 꺼진 모습, 프레임 1은 문이 열리고 창·간판·알전구에 불이 켜진 모습이에요.
  - 가게는 처음부터 열려 있어서 게임은 늘 프레임 1을 보여 주고, 문 쪽에 금빛을 더해요.
- **`prop-lightboard`**(가게 안 놀이 기계, 칸 하나): 받침대 위에 세워 둔 전구판이에요.
  - 작은 전구가 격자로 늘어서 있고, 전구 아래마다 작은 숫자 판(0·1 느낌의 작은 칸)이 붙어 있어요. 글자는 또렷하지 않아도 괜찮아요.
  - 판 위에 작은 불빛 붓(보라 로봇 붓)이 걸려 있어요.
  - 프레임 0·1은 전구가 번갈아 켜져요. 게임이 0.7초마다 바꾸고, 위쪽에 금빛 빛 무리를 더해요.
- **`prop-light-frame`**: 왼쪽 벽 앞에 세워 두는 작은 액자(받침 다리가 있어요)예요. 바닥에 바로 놓이니 다리 끝이 발 기준점에 닿아요.
  - 프레임 0은 불 꺼진 빈 액자(어두운 판, 꺼진 작은 칸이 희미하게)예요.
  - 프레임 1~6은 판마다 켜진 그림이에요. `src/data/minigames/light.ts`의 각 판 첫 숫자 그림과 칸 배치가 같아야 해요(1이 켜진 칸).
    - 1 `101`(점 둘), 2 `010`/`111`(버섯), 3 `101010`(점선), 4 `1111`×3줄(창문), 5 `110100`(숫자 띠), 6 5×5 하트(`01010`/`11111`/`11111`/`01110`/`00100`)
  - 켜진 칸은 밝은 노랑, 꺼진 칸은 어두운 남색이에요. 칸 하나는 2배 그림에서 4px 안팎이에요.
- **`prop-lamp-shelf`**: 작은 전등(스탠드·등불·전구)이 놓인 나무 진열대(장식)예요. 프레임 0·1은 불빛이 번갈아 켜져요. 가격표는 그리지 않아요.

### 2단계: 놀이 판 그림
놀이 창에서는 어두운 전구판(남색 바탕) 위에 세워서 40~60px로 커져요.
- **`icon-bulb-off`, `icon-bulb-on`**: 정면에서 본 둥근 전구와 소켓이에요.
  - 꺼진 전구는 회청색 유리, 켜진 전구는 노란 유리에 하이라이트와 빛 테두리가 있어요(게임이 빛 번짐을 조금 더해요).
  - 둘은 모양·크기·위치가 같고 색과 빛만 달라요. 숫자 판(0·1)은 게임이 전구 아래에 따로 붙이니 그림에 넣지 않아요.
- **`icon-light-brush`**: 불빛 붓이에요. 작은 보라 로봇 머리(눈 두 개)에 아래로 뾰족한 붓끝이 있고, 붓끝이 빛나요. 전구 위에 걸쳐 보이니 아래쪽이 붓끝이에요.
- **`icon-card-lightOn`, `icon-card-nextRow`**: 블록 카드예요. 다른 `icon-card-*`와 크기·선 두께·여백을 맞춰요.
  - 켜기: 전구와 반짝임(블록 색은 밝은 노랑이라 그림은 진한 선으로 또렷하게).
  - 다음 줄: 아래로 내려가 왼쪽 끝으로 꺾이는 화살표(줄 바꿈 느낌, 블록 색은 파랑).

2. `npm run assets && npm test && npm run build`가 통과해야 해요.
3. 검토판 `assets-preview/compare-15-<단계 번호>.png`를 만들어요(커밋되지 않아요).
   - **왼쪽 임시 그림 / 오른쪽 새 그림**으로 나란히 보여 줘요.
   - 1단계는 가게 방 미리보기(`lightshop` 맵 배치대로, 액자는 꺼짐·켜짐 둘 다)도 넣어요.
   - 2단계는 어두운 전구판 위에 켜진·꺼진 전구와 붓을 늘어놓은 모습도 넣어요.
4. 진행 기록 `docs/tasks/codex-15-progress.md`에 결과를 적어요(아래 형식).
5. 사용자가 단계마다 커밋하라고 했으면 작업 브랜치 `codex/15-lightshop`에 커밋 하나를 해요.
   - 메시지는 `C15-<단계>: <이름>`이에요(예: `C15-1: 불빛 가게 건물과 방 소품 2배 그림`).
   - main·push·머지·브랜치 바꾸기는 하지 않아요.

중간에 멈췄다가 다시 시작하면 진행 기록을 먼저 읽고 끝나지 않은 단계부터 이어서 해요.

## 게임에서 보기(포트 5176만 써요)
- `npm run dev -- --port 5176 --strictPort`로 켜요. **5173은 쓰지 않아요**(사용자의 저장 기록이 있어요).
- 그림만 볼 때: `http://localhost:5176/?gallery`
- 가게 안:
  1. 첫 화면 → "이 기기에서 체험" → 새 별명으로 시작해요.
  2. 가게는 마을 광장 왼쪽 위 집이에요. 처음부터 열려 있어요. 전구판 기계 옆에서 Space를 누르면 놀이 창이 열려요.
  3. 3~6판까지 열려면 브라우저 콘솔에 `__app.state.data.robiParts.push('memoryChip', 'dataLens', 'learningChip')`을 입력해요(5176의 이 기기 저장에만 남아요).
  4. 켜진 액자를 보려면 판을 성공하거나 `__app.state.setFlag('light:r6')`처럼 입력한 뒤 가게에 다시 들어가요.
