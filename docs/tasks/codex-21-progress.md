# C21 시연 준비

## 1단계 · 시연 모드

- `?demo`에서 제목 화면, 저장 프로필, HUD와 놀이 해금을 분리했어요. 장 이동은 실제 미션 보상과 준비물 로직으로 상태를 만들고 현재 상태 객체의 구독을 유지해요.
- 단위 테스트 418개와 빌드 통과. 5178의 일반 체험 기록을 만든 다음 10개 지점, 건물 6곳 입장, 놀이 6개 전체 해금, 블록·프롬프트·전투 바로 열기를 브라우저에서 확인했어요. 일반 모드에서 시연 단추는 숨겨졌고 과일 놀이에 잠긴 판이 있었어요. 일반 저장 문자열은 시연 전후 동일했고 시연 저장은 별도로 생겼어요. 페이지 예외 0개.
- 증거는 전용 브라우저 작업 폴더의 `output/playwright/c21-stage1-result.txt`예요. 실제 기기 터치는 별도 확인 대상이에요.

- 750회 검사에서 문서/패널 가로 넘침, 표시되는 이미지 로드 실패, 주요 단추의 40px 미달·스크롤 후 클릭 차단, 맵의 플레이어/HUD 표시, 콘솔·페이지·HTTP 오류를 확인했어요. 수정 후 자동 검사에서 검출 0건이에요. 각 화면의 첫 상태 검사이며 모든 문제 풀이 과정이나 모든 문장의 육안 교정은 아니에요.
- 320px 물결 지도가 패널 안쪽 283px를 넘어 314px로 그려져 유동 격자로 바꿨어요. 시작·목표 글자에는 작은 격자 전용 모양을 써서 두 글자를 한 줄로 보여 줘요. 좁은 시연 메뉴에서는 건물 이름이 단추 위 한 줄에 보여요.
- 휴대폰 전투 실행 단추가 높이 36px, 메뉴 켜짐 단추가 37px라서 40px 이상으로 키웠어요. 알림이 위에 겹쳐 클릭을 가로채던 문제도 고쳤어요. 미션·놀이·시연·대화 중에는 월드 알림이 숨겨져요.
- 0~8장 모두 시연 메뉴 → 길 안내 → 실제 NPC까지 걷기 → 첫 미션 시작을 확인했어요. 2·4장은 표지판 대화를 넘기고 진행했어요. 과일 가게 문과 실내 문 매트는 캔버스를 눌러 왕복했어요.
- 근거: `c21-accepted-result.txt`, `c21-*-320-final.png`, 별도 걷기 세션의 `c21-walk*-result.txt`. 테스트 418개·빌드 통과. 폰 화면은 브라우저 크기로 검증했어요.

## 3단계 · 본편과 건물 놀이

- 실제 미션 보상 지급 직전/직후에 열려 있는 판을 비교해요. 새 판이 있을 때만 결과 창 뒤에 건물별로 알리고, 시연 모드에서는 알림을 생략해요. 도감 ‘마을 놀이’에 여섯 건물의 판별 별과 합계·칭호를 표시했어요.
- 일반 로컬 체험에서 ‘로비 학습 칩’을 실제 선택·학습·시험·저장까지 진행했어요. 결과 창을 닫자 과일 가게 3판 알림이 생겼고, 같은 미션 재도전과 시연 모드에서는 알림이 없었어요. 도감의 빈 기록 및 시험용 별·칭호 기록, 5개 너비에서 가로 넘침 0 확인. `c21-connections-result.txt`.
- 이미 부품으로 연 판과 재도전 중복 알림 방지 테스트 포함 **420개** 통과, 빌드 통과. 기록 표시는 기존 미니게임 저장을 읽어요.

## 4단계 · 덩굴 조각과 동굴

- 덩굴 조각을 ‘슬라임과 만난 날의 기념품’으로 소개해요. 도감의 아이템 탭에서 실제 문구를 확인했어요.
- 동굴의 두 번째 테두리 색을 `0x367a96`으로 낮췄어요. 2장 동굴 (9,3), 높이 3에서 경계와 계단이 보이며 수정의 빛보다 덜 밝은 모습을 확인했어요. `c21-cave.png`, `c21-polish-result.txt`. 테스트 420개·빌드 통과.
