# Codex 작업 C19 — 마을 빵집과 주문서 빵집 그림

## 목표
2.5D 개선 4단계의 다섯 번째 건물이에요. 엔진은 Claude가 먼저 만들었고, 지금은 임시 그림으로 끝까지 돌아가요.
- 마을 광장 오른쪽 아래 빈 집 자리(16,13)가 **마을 빵집**이에요.
  - 처음부터 열려 있어요. 걸어 들어가면 실내 맵 `bakery`로 가요.
- 빵집 안 주문서 오븐에서 **주문서 빵집** 6판을 해요(7장 프롬프트 연습).
  - 손님이 원하는 케이크 그림을 보고, 주문서 칸(맛·모양·올릴 것·글씨 판)마다 카드를 골라 오븐에 부탁해요.
  - 빈 칸이나 애매한 카드('예쁜 모양으로' 등)는 오븐이 마음대로 골라서 그림과 달라져요.
  - 개인정보 카드(이름·반·주소)는 오븐이 굽지 않아요.
  - 결과를 보고 주문서를 고쳐 다시 물어요. 운이나 코인은 없어요.
- 판을 처음 성공하면 빵집 왼쪽 벽 앞 빈 진열대에 그 판의 케이크가 놓여요.

이번 작업은 **새 그림 5개(모두 2배)**예요. 두 단계로 나눠 단계마다 커밋해요.
- 빵집 안의 벽·바닥·창문·스탠드·화분·문 매트는 C13 공방 그림을 그대로 같이 써요.
- 놀이 창의 케이크 그림(손님 그림·구운 케이크)은 코드가 16×16 픽셀로 그려요(`src/minigames/bakery/cakeArt.ts`). 이번에 그리지 않아요.

## 공통 규칙
- **팔레트**: 64색이 가득 찼어요. 지금 색만 써요. 모자라면 가까운 색으로 그리고 진행 기록에 적어요.
- **원본**: 2배 원본은 `assets-src/hires/<kind>/<key>.txt`예요. 원본이 아직 없는 키는 `npm run assets`가 건너뛰어요(게임은 임시 그림). 그래서 단계마다 그린 키만으로도 통과해요.
- **규격**: 크기는 정확히 목록 × 2, 발은 아래 가운데에서 4px 위, 반투명 픽셀 없음, 발밑 그림자 없음(게임이 그려요).
- **스타일**
  - C11~C18처럼 빛은 왼쪽 위, 바깥 외곽선, 재질마다 3~4단 명암이에요.
  - 빵집은 다른 마을 건물(공방 분홍, 택배소 파랑, 불빛 가게 보라, 지도방 초록)과 한눈에 구별돼요. 빨강·흰 줄무늬 차양과 케이크 간판이 좋아요.
- 실제 빵집·제과 브랜드의 로고나 글자를 그리지 않아요. **돈·동전·가격표도 그리지 않아요**(놀이는 주문서로만 해요).

## 단계(차례대로 해요)
| 단계 | 이름 | 키(2배 PNG 크기) |
|---|---|---|
| 1 | 빵집 건물과 방 소품(4) | `prop-bakery` 128×96(2프레임), `prop-oven` 128×96(2프레임), `prop-cake-stand` 224×48(7프레임), `prop-bread-shelf` 64×64 |
| 2 | 놀이 아이콘(1) | `icon-cake` 32×32 |

### 1단계: 빵집 건물과 방 소품

#### `prop-bakery`(마을에 서 있는 빵집 겉모습)
- C11 `prop-house`, C13~C15 건물, C18 `prop-route-house`와 같은 크기·시점·지붕 방식이에요.
- 문 위에 케이크 간판, 처마에 빨강·흰 줄무늬 차양을 달아요.
- 프레임 0은 문이 닫히고 불이 꺼진 모습, 프레임 1은 문이 열리고 창에 불이 켜진 모습이에요.
- 빵집은 처음부터 열려 있어서 게임은 늘 프레임 1을 보여 주고, 문 쪽에 금빛을 더해요.

#### `prop-oven`(빵집 안 놀이 기계, 칸 하나)
- 둥근 창이 있는 오븐이에요. 앞에 주문서 꽂이(작은 종이 카드)가 있어요.
- 프레임 0·1은 오븐 창 불빛이 번갈아 밝아져요. 게임이 0.7초마다 바꾸고, 오븐 창 높이에 따뜻한 빛을 더해요.

#### `prop-cake-stand`(왼쪽 벽 앞에 세워 두는 작은 진열대)
- 받침 다리가 있어서 바닥에 바로 놓이니 다리 끝이 발 기준점에 닿아요. C15 `prop-light-frame`, C18 `prop-route-map`과 같은 크기·자리 방식이에요.
- 프레임 0은 빈 접시예요.
- 프레임 1~6은 판마다 (마지막 손님의) 케이크가 접시에 놓인 모습이에요. 게임 속 케이크 그림(`cakeArt.ts`)과 **모양·크림 색·올릴 것·글씨 판 점 색**이 같아야 해요.
  1. 딸기 맛(분홍 크림) · 하트 모양 · 올릴 것 없음 · 글씨 판 없음
  2. 초코 맛(갈색 크림) · 둥근 모양 · 체리 셋 · 글씨 판 없음
  3. 민트 맛(민트 크림) · 별 모양 · 꽃 셋 · 글씨 판 없음
  4. 바닐라 맛(크림색) · 네모 모양 · 별사탕 셋 · 흰 글씨 판에 빨간 점(생일 축하해요)
  5. 바닐라 맛 · 하트 모양 · 별사탕 셋 · 흰 글씨 판에 파란 점(고마워요)
  6. 민트 맛 · 별 모양 · 별사탕 셋 · 흰 글씨 판에 노란 점(힘내요)
  - 글씨 판에는 읽을 글자를 쓰지 않고 점 색만 다르게 해요.
  - 2배 그림에서는 크림 흘러내림·하이라이트를 더해도 좋아요. 다만 위 특징이 바로 보여야 해요.

#### `prop-bread-shelf`
빵(식빵·바게트·둥근 빵)이 놓인 나무 선반이에요(장식).

### 2단계: 놀이 아이콘
- **`icon-cake`**: 작은 케이크 아이콘이에요(분홍 크림 둥근 케이크에 딸기).
- 판 고르기 카드(48px)와 오븐 표시(28px)에 써요.
- 어두운 창(#262c3b)과 크림색 바탕 위에서 모두 또렷하게, 바깥 외곽선을 짙게 해요.

## 단계마다 할 일
1. 그 단계의 2배 원본을 그려요.
2. `npm run assets && npm test && npm run build`가 통과해야 해요.
3. 검토판 `assets-preview/compare-19-<단계 번호>.png`를 만들어요(커밋되지 않아요).
   - **왼쪽 임시 그림 / 오른쪽 새 그림**으로 나란히 보여 줘요.
   - 1단계는 빵집 미리보기도 넣어요(`bakery` 맵 배치대로, 진열대는 빈 접시·케이크 둘 다).
   - 1단계는 진열대 1~6프레임 옆에 게임 속 케이크 그림(`cakePixels`)을 나란히 놓아 같은지 보여 줘요.
   - 2단계는 아이콘을 어두운 창·크림 바탕 위 48px·28px로 보여 줘요.
4. 진행 기록 `docs/tasks/codex-19-progress.md`에 결과를 적어요(아래 형식).
5. 사용자가 단계마다 커밋하라고 했으면 작업 브랜치 `codex/19-bakery`에 커밋 하나를 해요.
   - 메시지는 `C19-<단계>: <이름>`이에요(예: `C19-1: 빵집 건물과 방 소품 2배 그림`).
   - main·push·머지·브랜치 바꾸기는 하지 않아요.

중간에 멈췄다가 다시 시작하면 진행 기록을 먼저 읽고 끝나지 않은 단계부터 이어서 해요.

## 게임에서 보기(포트 5176만 써요)
- `npm run dev -- --port 5176 --strictPort`로 켜요. **5173은 쓰지 않아요**(사용자의 저장 기록이 있어요). 다 쓰면 개발 서버를 꺼 주세요.
- 그림만 볼 때: `http://localhost:5176/?gallery`
- 빵집 안
  1. 첫 화면 → "이 기기에서 체험" → 새 별명으로 시작해요.
  2. 빵집은 마을 광장 오른쪽 아래 집이에요. 처음부터 열려 있어요. 오븐 옆에서 Space를 누르면 놀이 창이 열려요.
     - 바로 가려면 브라우저 콘솔에 `__app.game.scene.getScene('World').scene.restart({ map: 'bakery' })`를 입력해요.
  3. 3~6판까지 열려면 콘솔에 `__app.state.data.robiParts.push('talkModule')`을 입력해요(5176의 이 기기 저장에만 남아요).
  4. 케이크가 놓인 진열대를 보려면 판을 성공하거나 `__app.state.setFlag('cake:r6')`처럼 입력한 뒤 빵집에 다시 들어가요.
