# C23 마을과 이야기

## 1단계 · 상점 구매와 학습 우회 방지

가격·해금·보유량을 구매 직전에 검사해요. 실패하면 기록이 그대로이고, 구매 장비는 가방에 들어가요. 라운드 사이에 사과·젤리를 쓰면서 공격만 반복하자 사과 5개에서는 Lv3~5 모두, 2개에서는 Lv4·5에서 수호자를 이겼어요. 1장 완료 전 사과 구매 한도 1개에서 모두 패배했고, 완료 후 한도는 5개예요. 젤리 한도는 3개예요. 5183 일반 체험에서 망치 잠금·구매·중복 차단, 가방의 착용 단추를 확인했어요. 433개 테스트·빌드 통과.

## 2단계 · 하루의 탐험 가게

마을 연습 뒤 (3,10)에 하루, (2,10)에 매대를 표시해요. 5183 일반 체험에서 하루 곁에서 Space로 열고 망치를 샀어요. 동전 1000→950, 중복 단추 비활성, 가방 착용 안내와 탭의 키보드 동작을 확인했어요. 1366·390·320px 창 가로 넘침 0, 433개 테스트·빌드 통과. 꾸미기 상품은 3단계에서 추가해요.

## 3단계 · 마을 장식 여섯 세트

장식 6종(소품 12개)을 고정 위치에 두고 구매 플래그로 표시해요. 5183에서 전부 구매해 550개 차감, 중복 구매 차단, 닫자마자 표시, 새로고침·이어하기 후 12개 유지를 확인했어요. 3개 화면 크기와 마을 문·NPC·표지판·보물상자 도달 검사, 434개 테스트·빌드 통과.

## 4단계 · 도감 수집 경로 완성

앵무새 대장은 기존 ch7-boss-m1 완료 기록으로 도감에서 보여요. 별도 저장 이관 없이 5183 일반 체험의 완료 전 미표시, 완료 기록을 가진 저장을 다시 연 뒤 표시, 전투 기록 불변을 확인했어요. 모든 몹·아이템의 획득 경로 검사 포함 435개 테스트·빌드 통과.

## 5단계 · 건물 안 여섯 인물

건물 안 6명에게 각 3개의 순환 대사를 넣었어요. 일반 체험에서 각 인물 곁에서 Space로 말을 걸어 첫 대사를 읽고 닫았어요. 여섯 방 모두 입장 칸 주변을 비웠고, 기계·인물·문 매트 도달 검사 포함 441개 테스트·빌드 통과.

## 6단계 · 장 입구와 마을 귀환 이야기

1~8장의 입장·완료 장면(16편)을 만들었어요. 일반 체험에서 숲 첫 입장과 재방문 생략, 1·2장 완료 기록으로 귀환할 때 2장만 재생, 대화를 닫은 뒤 플래그 기록을 확인했어요. 엔딩 조건 저장에서는 엔딩만 재생하고 확인 뒤 8장 완료 장면까지 본 것으로 표시해요. 시연 모드 장 이동·건물 입장 때 장면과 플래그가 없었어요. 444개 테스트·빌드 통과. Claude 검토: 첫 구매의 동전·아이템 단일 변경 알림, 옛 저장·엔딩·시연에서의 장면 선택, 3~4학년에게 반복·조건 대사가 자연스러운지. 실물 터치와 학급 동기화는 미검증. 범위 밖 필요한 변경 없음.
