# C24 미로 공작소

## 1단계 · 미로 규칙과 나눔 코드

7×7 미로의 두 끝·최단 걸음·갈림·막다른 길과 13글자 검사값 코드를 구현했어요. 작품은 정상 판·검증된 코드만 저장해요. 기존 시연 시작과 브라우저의 실제 모듈로 코드 왕복을 확인했어요. 테스트 431개와 빌드 통과.

## 2단계 · 마을 미로 공작소 건물과 방

마을 (21,16)의 문과 실내 설계대·액자 6개·선반 및 문 매트에 임시 그림을 연결했어요. 실제 캔버스에서 문과 매트를 눌러 왕복했고 액자 여섯 개가 보였어요. 경로 테스트 포함 432개 및 빌드 통과.
