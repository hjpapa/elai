# C24 미로 공작소

## 1단계 · 미로 규칙과 나눔 코드

7×7 미로의 두 끝·최단 걸음·갈림·막다른 길과 13글자 검사값 코드를 구현했어요. 작품은 정상 판·검증된 코드만 저장해요. 기존 시연 시작과 브라우저의 실제 모듈로 코드 왕복을 확인했어요. 테스트 431개와 빌드 통과.

## 2단계 · 마을 미로 공작소 건물과 방

마을 (21,16)의 문과 실내 설계대·액자 6개·선반 및 문 매트에 임시 그림을 연결했어요. 실제 캔버스에서 문과 매트를 눌러 왕복했고 액자 여섯 개가 보였어요. 경로 테스트 포함 432개 및 빌드 통과.

## 3단계 · 설계와 프로그램 실행 및 친구 코드 놀이

7×7 설계·시작/깃발 이동·조건 표시, 프로그램 편집과 실행 애니메이션, 최단 길 별과 칭호·작품 저장, 친구 코드·섬 친구 3개·복사를 만들었어요. 실제 브라우저에서 시험용 놀이 호스트로 320px 1판 설계·성공, 틀린 코드 거절, 6판에 1판 코드 입력·성공을 확인했어요. 공개 목록 연결은 4단계예요. 테스트 432개·빌드 통과.

## 4단계 · 도감·시연 메뉴·저장 연결

일반 체험·시연 모드 각각 6판을 실제 설계·블록 실행으로 완료했어요. 두 모드 모두 새로고침 뒤 18/18별·액자 1~6·작품 6개·칭호가 남았고 동전과 경험치는 시작값 그대로였어요. 일반 1판 코드를 시연 6판에서 복사 입력해 풀었어요. 일반 4·5판의 잠금을 확인한 다음 시험용 부품을 설정했고, 해금 알림과 재도전 중복 방지는 순수 테스트로 확인했어요. 1366/390/320px에서 플레이했고 문서 가로 넘침·페이지 예외가 없었어요. 433개 테스트·빌드 통과.

## 5단계 · 공작소 건물과 소품 고해상도 그림

노란 채광창 지붕과 남색 격자 벽, 문 위 미로 간판을 그렸어요. 청록 설계 화면 두 상태, 빈 액자와 여섯 가지 미로 판화, 자·연필·접은 도면 선반을 만들었어요.

## 6단계 · 미로 아이콘과 최종 플레이 확인

접힌 크림색 도면, 남색 미로 벽, 청록 경로와 빨간 도착 깃발을 32×32 아이콘에 그렸어요. assets-preview/compare-24-2.png에서 어두운 창과 크림 바탕에 48px·28px를 비교했고 판 카드가 32px 원본을 48px로 표시하는 것도 확인했어요.

최종 그림으로 마을 건물을 눌러 방에 들어가 빈 액자·완성 액자 6개를 확인했어요. 일반과 시연에서 각각 6판을 다시 직접 설계·실행해 별 18개와 작품 6개씩 얻고, 새로고침 뒤 칭호와 액자도 복원했어요. 일반 4·5판은 먼저 잠금을 확인한 뒤 시험용 부품을 넣었어요. 일반 1판 작품을 시연 6판에 입력했고 1366×768, 390×844, 320×640에서 설계·실행 화면 격자와 단추 가로 넘침·페이지 예외 0건이었어요. 별도 시연에서 키보드로 길을 놓고 4걸음 미로를 6걸음으로 풀어 별 2개를 받았고, 코드 복사 뒤 시스템 클립보드와 표시 코드가 같았어요.

npm run assets 성공(247개 모두 density 2, 누락 0, 2048×2048), npm test 35파일·433개 통과, npm run build 통과. 실제 휴대폰 터치, 화면 낭독기, 학생 수업은 미확인이에요. Claude는 5판에서 ‘물결 따라가기’를 처음 읽는 학생의 이해도와 4·5판 판정 및 새 저장 필드 정리, 시연 목록·등록기 연결을 함께 검토해 주세요. 현재 후속 구현이나 지시서 밖 필요한 변경은 없어요.
