# 그림 규격 (계약)

이 문서와 `src/game/assets.ts`가 그림의 계약이에요. 키 이름·크기·프레임 수는 `assets.ts` 목록이 기준이고, 바꾸거나 새 키를 넣으려면 Claude 승인이 필요해요.

## 스타일
- 픽셀아트. 밝고 둥근 느낌, 초등학생이 보기에 무섭지 않게.
- 외곽선은 1px, 팔레트 안의 짙은 색. 빛은 왼쪽 위에서 와요.
- **공용 팔레트 하나**: `assets-src/palette.json`에 64색 이내(`#rrggbb`)로 정의하고 모든 그림이 그 색만 써요.
  - 처음 32색은 바꾸거나 지우지 않아요(옛 그림이 그 색을 써요). 새 색은 뒤에 붙여요.
- 픽셀 알파는 0(투명) 또는 255(불투명)만 써요. 반투명 픽셀은 쓰지 않아요.
- 기존 게임의 캐릭터·타일을 따라 그리지 않아요.

## 종류별 크기와 기준점
| 종류 | 프레임 크기 | 설명 |
|---|---|---|
| tile | 32×16 | 아이소 마름모 윗면(2:1). 마름모 바깥은 투명. 이음새가 보이지 않게 가장자리까지 채워요 |
| block | 32×24 | 높이 있는 칸. 위 16px = 윗면 마름모, 아래 8px = 옆면(왼쪽 옆면은 조금 밝게, 오른쪽은 어둡게) |
| block(높은 벽) | 32×56 | 건물 안 뒤쪽 벽. 위 16px = 윗면(벽 두께), 아래 40px = 옆면(아래 "건물 안 높은 벽") |
| prop | 목록 참고(최대 32×48) | 나무·집·상자 같은 소품 |
| char | 16×24 × 10프레임 | 캐릭터 |
| overlay | 16×24 × 10프레임 | 캐릭터 위에 겹치는 모자·도구·로비 부품 |
| mob | 16·24·48 정사각형 × 4프레임 | 몹 |
| icon | 16×16 | 아이템·카드·UI 아이콘. 가운데 정렬, 1px 여백 |
| fx | 목록 참고 | 효과(가로 프레임) |
| ui | 목록 참고(8px 단위) | 화면 테두리·단추·말풍선·조이스틱. 9칸 나눔(아래 "화면 테두리") |

- **발 기준점**: prop·char·overlay·mob은 그림 아래 가운데에서 2px 위가 "발"이에요. 게임은 이 점을 칸 가운데에 놓아요. 아래 2줄에는 그림자를 넣어도 돼요.
- **block 기준점**: 아래에서 8px 위가 바닥 마름모의 중심이에요(32×24 블록은 위에서 16px, 높은 벽 32×56은 위에서 48px).
- 여러 프레임은 **가로로 이어 붙여요**. PNG 크기 = (프레임 너비 × 프레임 수) × 프레임 높이.

### 캐릭터 10프레임 순서
| 프레임 | 내용 |
|---|---|
| 0 | 앞 대기(화면 오른쪽 아래를 봐요) |
| 1~4 | 앞으로 걷기 |
| 5 | 뒤 대기(화면 오른쪽 위를 봐요) |
| 6~9 | 뒤로 걷기 |

왼쪽을 보는 모습은 게임이 좌우를 뒤집어서 만들어요.

### 겹침 레이어
- 모자·도구(`equip-*`)는 `char-player` 위에, 로비 부품(`robi-part-*`)은 `char-robi` 위에 그대로 얹었을 때 맞게 그려요.
- 같은 10프레임 격자에 모자·도구만 그리고 나머지는 투명으로 둬요.

### 몹 4프레임 순서
| 프레임 | 내용 |
|---|---|
| 0~1 | 대기(살짝 움직임) |
| 2 | 맞음(찡그림) |
| 3 | 정화됨(웃는 얼굴, 밝은 색) |

### 건물 안 높은 벽
실내 맵(예: 마을 공방)은 뒤쪽 두 변(맵 x=0 줄과 y=0 줄)에만 높은 벽을 세우고, 앞쪽은 잘라 낸 인형의 집처럼 바닥 두께만 보여 줘요.
- 크기 32×56(2배 64×112). 위 16px은 윗면 마름모(벽 두께), 그 아래로 두 옆면이 40px 내려와요.
- 왼쪽 옆면 = 오른쪽 뒤 벽(y=0 줄)의 방 쪽 면이라 밝게, 오른쪽 옆면 = 왼쪽 뒤 벽(x=0 줄)의 방 쪽 면이라 조금 어둡게 그려요.
- 같은 줄에 이어 놓았을 때 옆면 무늬·굽도리·윗면 테두리가 끊기지 않아요. 창문 벽은 두 옆면의 같은 높이에 창을 내요.

### 화면 테두리(ui)
- 창·단추·말풍선·칸은 **9칸 나눔**으로 늘려 써요. 네 모서리 8px(2배 그림은 16px)는 그대로, 가장자리와 가운데는 늘어나요.
- 가운데 면은 단색이나 아주 약한 무늬로 그려요(늘어나도 어색하지 않게). 글씨가 올라가니 밝고 차분하게요.

## 고해상도 그림(2배 밀도)
2.5D 개선 기간(2026-11-06~)부터 새로 그리는 그림이에요. 옛 그림과 섞여도 게임이 같은 크기로 그려요.
- **크기**: 목록(`assets.ts`) 크기의 정확히 2배(프레임 너비·높이 모두). 예: 타일 64×32, 블록 64×48, 캐릭터 32×48 ×10프레임, 아이콘 32×32.
- **매니페스트**: 그 키 항목에 `"density": 2`를 적어요. 아틀라스 프레임도 2배 크기예요.
- **기준점**: 비율이 같아요. 발은 아래 가운데에서 4px 위, 블록 바닥 마름모의 중심은 아래에서 16px 위(블록은 위에서 32px, 높은 벽은 위에서 96px).
- **외곽선**: 바깥 외곽선 1px. 검정 대신 그 면 색의 가장 짙은 단계를 써요(선택 외곽선). 안쪽 선은 꼭 필요한 곳만.
- **명암**: 재질마다 3~4단계(밝은 면, 기본, 그늘, 짙은 그늘). 그늘은 조금 차갑게(푸르게), 밝은 곳은 조금 따뜻하게(노랗게). 빛은 왼쪽 위.
- **질감**: 넓은 면에만 작은 무늬(풀잎, 나뭇결, 돌 틈)를 넣고, 같은 무늬가 줄지어 반복돼 보이지 않게 해요. 점 섞기(디더링)는 넓은 그라데이션에만 조금.
- **피하기**: 모든 면 둘레를 어둡게 칠하는 "베개 명암", 1px 점 잡티, 반투명 픽셀(여전히 쓰지 않아요).
- **캐릭터**: 머리가 큰 귀여운 비율(키의 약 40%가 머리), 눈·입이 보이는 얼굴, 실루엣만 봐도 누구인지 알 수 있게. 걷기 4프레임은 팔·다리가 번갈아 움직이고 몸이 1px 오르내려요.
- **겹침 레이어**: 몸 그림과 같은 밀도로 그려요(2배 몸에는 2배 모자·도구).
- **그림자**: 고해상도 그림에는 발밑 그림자를 넣지 않아요. 게임이 반투명 그림자를 따로 그려요.

## 파일과 매니페스트
- **원본**: `assets-src/`의 텍스트 격자(글자 하나 = 픽셀 하나, 글자 → 팔레트 색). 형식은 `assets-src/README.md`에 적어 둬요.
- **생성**: `npm run assets`(`scripts/build-assets.mjs`)가 아래를 만들어요.
  - `public/assets/<kind>/<key>.png`
  - `public/assets/manifest.json`
    ```json
    { "version": 1, "palette": ["#1b1f2a", "..."], "assets": [{ "key": "tile-grass", "file": "tile/tile-grass.png", "density": 2 }] }
    ```
  - `assets-preview/contact-sheet.png`: 모든 그림을 키워 한 장에 모은 검토용 그림(git에 올리지 않아요). 같은 크기로 비교되게 옛 그림은 4배, 2배 그림은 2배로 키워요.
- **검사**: `tests/assets.test.ts`가 매니페스트 키가 목록에 있는지, PNG 크기(밀도 반영), 팔레트(64색 이내, 처음 32색 그대로), 팔레트 밖 색, 반투명 픽셀을 확인해요.
- **게임에서 보기**: `npm run dev` 뒤 주소 끝에 `?gallery`를 붙이면 바닥 위에 세운 모습과 모든 그림을 볼 수 있어요.
- **임시 그림**: 매니페스트에 없는 키는 게임이 단색 도형으로 대신 그려요. 그래서 그림을 일부만 만들어도 게임은 돌아가요.
