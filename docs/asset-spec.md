# 그림 규격 (계약)

이 문서와 `src/game/assets.ts`가 그림의 계약이에요. 키 이름·크기·프레임 수는 `assets.ts` 목록이 기준이고, 바꾸거나 새 키를 넣으려면 Claude 승인이 필요해요.

## 스타일
- 픽셀아트. 밝고 둥근 느낌, 초등학생이 보기에 무섭지 않게.
- 외곽선은 1px, 팔레트 안의 짙은 색. 빛은 왼쪽 위에서 와요.
- **공용 팔레트 하나**: `assets-src/palette.json`에 32색 이내(`#rrggbb`)로 정의하고 모든 그림이 그 색만 써요.
- 픽셀 알파는 0(투명) 또는 255(불투명)만 써요. 반투명 픽셀은 쓰지 않아요.
- 기존 게임의 캐릭터·타일을 따라 그리지 않아요.

## 종류별 크기와 기준점
| 종류 | 프레임 크기 | 설명 |
|---|---|---|
| tile | 32×16 | 아이소 마름모 윗면(2:1). 마름모 바깥은 투명. 이음새가 보이지 않게 가장자리까지 채워요 |
| block | 32×24 | 높이 있는 칸. 위 16px = 윗면 마름모, 아래 8px = 옆면(왼쪽 옆면은 조금 밝게, 오른쪽은 어둡게) |
| prop | 목록 참고(최대 32×48) | 나무·집·상자 같은 소품 |
| char | 16×24 × 10프레임 | 캐릭터 |
| overlay | 16×24 × 10프레임 | 캐릭터 위에 겹치는 모자·도구·로비 부품 |
| mob | 16·24·48 정사각형 × 4프레임 | 몹 |
| icon | 16×16 | 아이템·카드·UI 아이콘. 가운데 정렬, 1px 여백 |
| fx | 목록 참고 | 효과(가로 프레임) |

- **발 기준점**: prop·char·overlay·mob은 그림 아래 가운데에서 2px 위가 "발"이에요. 게임은 이 점을 칸 가운데에 놓아요. 아래 2줄에는 그림자를 넣어도 돼요.
- **block 기준점**: 위에서 16px 지점이 바닥 마름모의 중심이에요.
- 여러 프레임은 **가로로 이어 붙여요**. PNG 크기 = (프레임 너비 × 프레임 수) × 프레임 높이.

### 캐릭터 10프레임 순서
| 프레임 | 내용 |
|---|---|
| 0 | 앞 대기(화면 오른쪽 아래를 봐요) |
| 1~4 | 앞으로 걷기 |
| 5 | 뒤 대기(화면 오른쪽 위를 봐요) |
| 6~9 | 뒤로 걷기 |

왼쪽을 보는 모습은 게임이 좌우를 뒤집어서 만들어요.

### 겹침 레이어
- 모자·도구(`equip-*`)는 `char-player` 위에, 로비 부품(`robi-part-*`)은 `char-robi` 위에 그대로 얹었을 때 맞게 그려요.
- 같은 10프레임 격자에 모자·도구만 그리고 나머지는 투명으로 둬요.

### 몹 4프레임 순서
| 프레임 | 내용 |
|---|---|
| 0~1 | 대기(살짝 움직임) |
| 2 | 맞음(찡그림) |
| 3 | 정화됨(웃는 얼굴, 밝은 색) |

## 파일과 매니페스트
- **원본**: `assets-src/`의 텍스트 격자(글자 하나 = 픽셀 하나, 글자 → 팔레트 색). 형식은 `assets-src/README.md`에 적어 둬요.
- **생성**: `npm run assets`(`scripts/build-assets.mjs`)가 아래를 만들어요.
  - `public/assets/<kind>/<key>.png`
  - `public/assets/manifest.json`
    ```json
    { "version": 1, "palette": ["#1b1f2a", "..."], "assets": [{ "key": "tile-grass", "file": "tile/tile-grass.png" }] }
    ```
  - `assets-preview/contact-sheet.png`: 모든 그림을 4배로 키운 검토용 한 장(git에 올리지 않아요)
- **검사**: `tests/assets.test.ts`가 매니페스트 키가 목록에 있는지, PNG 크기, 팔레트 밖 색, 반투명 픽셀을 확인해요.
- **임시 그림**: 매니페스트에 없는 키는 게임이 단색 도형으로 대신 그려요. 그래서 그림을 일부만 만들어도 게임은 돌아가요.
